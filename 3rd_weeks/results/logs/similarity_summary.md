# 논문–로컬 수치 유사도 로그

대상은 왜도 3, SD 비 1.10, 표본수 7단계에서의 `2 family × 2 tests × 7 n = 28`개 기각률이다. 단위 `%p`는 퍼센트포인트다.

## 전체

| 지표 | 값 |
|---|---:|
| 비교 수 | 28 |
| 평균 편향 | -0.104%p |
| MAE | 0.233%p |
| RMSE | 0.318%p |
| 최대 절대차 | 0.920%p |
| 범위 정규화 RMSE | 0.331% |
| Pearson r | 0.999924 |
| R² | 0.999848 |
| Lin CCC | 0.999912 |
| 회귀 절편 | -0.0695%p |
| 회귀 기울기 | 0.997802 |
| 0.5%p 이내 | 92.86% (26/28) |
| 1.0%p 이내 | 100% (28/28) |
| 결합 MC 오차 기준 통과 | 100% (28/28) |
| 평균 / 최대 절대 z | 0.622 / 2.653 |

## 하위 집단

| 범위 | MAE(%p) | RMSE(%p) | 최대차(%p) | r | CCC | MC 통과율 |
|---|---:|---:|---:|---:|---:|---:|
| gamma | 0.244 | 0.318 | 0.790 | 0.999958 | 0.999949 | 100% |
| lognormal | 0.222 | 0.318 | 0.920 | 0.999720 | 0.998705 | 100% |
| Welch | 0.199 | 0.281 | 0.790 | 0.900248 | 0.899094 | 100% |
| WMW | 0.267 | 0.350 | 0.920 | 0.999957 | 0.999932 | 100% |

Welch의 상관계수가 상대적으로 낮은 이유는 결과가 2.8–5.1%의 좁은 구간에 모여 작은 Monte Carlo 흔들림이 상관계수에 크게 반영되기 때문이다. 절대오차 기준에서는 Welch MAE가 0.199%p로 매우 작다. 따라서 상관계수만으로 재현성을 판단하지 않고 MAE·RMSE·MCSE 판정을 함께 사용한다.

## 판정

절대차가 모두 1%p 이내이고, 전체 회귀가 항등선에 가깝고, 28개 모두 사전 정의한 결합 Monte Carlo 기준을 통과했다. 논문과 로컬 결과는 수치 수준과 변화 패턴 모두에서 매우 높은 유사성을 보인다.
