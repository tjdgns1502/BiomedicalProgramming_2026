# 실험·조절 에이전트

입력: `config.R`, 검증 에이전트의 직전 `validation.csv`, `reconciliation.md`.

1. 논문에 명시된 표본수·왜도·표준편차비·반복수·검정을 고정한다.
2. 모호한 정렬 정의만 사전 후보(`mean`, `median`) 안에서 변경한다.
3. 각 후보를 같은 반복수로 실행하고 목표 수치와의 표준화 차이가 가장 작은 후보를 선택한다.
4. 선택 근거, 시드, 반복수, 변경 전후를 로그에 기록한 뒤 결과를 검증 에이전트에 넘긴다.
5. 허용된 후보가 소진되거나 3라운드에 도달하면 조절을 중단한다.

금지: 시드 쇼핑, 결과 삭제, 목표값 직접 대입, 사후적 임계값 변경.
