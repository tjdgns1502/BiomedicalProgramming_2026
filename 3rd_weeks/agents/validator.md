# 독립 검증 에이전트

입력: 논문 참조값, 실험 에이전트가 고정한 코드와 새 결과.

1. 생성분포의 평균·중앙값·표준편차·왜도와 `Pr(X<Y)`를 독립 계산한다.
2. Welch 자유도를 Satterthwaite 식으로 다시 계산한다.
3. 로컬 기각률과 논문 기각률의 차이를 결합 MCSE와 반올림 오차로 표준화한다.
4. `|z| <= config$validation_z`만 통계적 일치로 판정한다.
5. 불일치를 난수 오차, 검정 구현, 분포 정렬, 논문 서술 모호성, 미공개 구현 중 하나로 분류한다.
6. 전체·분포별·검정별로 MAE, RMSE, 최대 절대차, 편향, Pearson r, R², Lin CCC, 회귀 기울기·절편과 허용오차 통과율을 기록한다.

검증 에이전트는 분석 코드를 고치지 않고 `results/tables/validation.csv`와 로그만 작성한다.
