# 다음 설명을 위한 사전지식 수준

[[00-start 처음부터 따라가는 분석 흐름|전체 흐름]]

> 이 평가는 10개 질문에서 추론한 **설명 수준의 설정**입니다. 시험이나 능력 진단이 아니며 수학·코딩·전공 전체 수준을 평가하지 않습니다.

## 다음 요청에 적기 좋은 문장

> 의생명 연구의 문제의식은 이해하지만, 통계는 데이터 한 행·변수의 종류·기술통계부터 설명이 필요한 입문 수준입니다. 계산 예시를 따라가며 설명해 주세요. 회귀·오즈·공변량 보정의 사전지식은 가정하지 말고, 지표 선택과 연구 설계의 타당성은 충분히 깊게 다뤄 주세요.

‘통계를 전혀 모른다’고만 쓰면 논문 비판에 필요한 깊이까지 줄어들 수 있습니다. **용어의 익숙함과 비판적 질문의 수준은 별개**이므로 위처럼 나누어 전달하는 것이 더 정확합니다.

## 질문에서 확인되는 것과 아직 모르는 것

| 관찰 근거 | 설명에 반영할 판단 |
|---|---|
| FI 기준이 타당한지, 지표가 대표적인지 질문 | 측정의 타당성과 연구 설계에 대한 관심이 있음 |
| 표본 대표성과 관찰자료의 한계를 질문 | 큰 표본과 좋은 근거가 같은지 비판적으로 보려 함 |
| 연속형·범주형, 중앙값·IQR 설명 요청 | 자료형과 기술통계를 건너뛰지 않아야 함 |
| 오즈·회귀 가정·보정 역할 질문 | 회귀 결과의 언어와 전제를 처음부터 연결해야 함 |
| 병렬 나열로 흐름이 안 보인다고 지적 | 개념마다 입력·처리·출력·다음 단계가 필요 |
| 수학·코딩 경험을 직접 밝히지 않음 | 해당 능력을 낮다고 판단하지 않음 |

실무적으로는 **‘기초통계 입문, 의생명 논문을 비판적으로 읽으려는 학습자’**라는 설정이 맞습니다. 향후 정확한 수준은 아래 질문에 본인의 말로 답할 수 있는지로 조정할 수 있습니다.

## 이전 설명에서 실제로 부족했던 것

| 부족한 연결 | 혼란이 생긴 이유 | 이번 자료에서 바꾼 방식 |
|---|---|---|
| 원자료의 모양 | 추상적 변수 이름부터 등장 | 같은 8명의 가상 표에서 시작 |
| FI → Y → 로지스틱 | 이분화와 모형 선택이 한 단계처럼 보임 | 점수 구성, 기준 적용, 모형 선택 분리 |
| 확률 → 오즈 → OR | 숫자의 분모와 해석이 생략됨 | 20/100과 20/80부터 계산 |
| 로그·사분위·보정 | 모두 ‘전처리’처럼 묶여 목적이 섞임 | 척도 변경·범주화·공변량 통제를 구별 |
| 병렬 분석 가지 | 각각이 어느 질문에 답하는지 불명확 | 주 분석 후 보완 분석의 학습 순서 제시 |
| 사실·해설·비판 | 저자가 한 일과 권장 방법이 섞일 수 있음 | 원문 사실·교육 예시·추가 제안 표시 |
| 개념과 적용의 밀도 | 기초 설명 중 갑자기 원문 수치가 등장 | 한 단계에 개념 페이지와 논문 페이지를 짝지음 |

따라서 설명이 어려웠던 원인을 전부 학습자의 지식 부족으로 돌릴 필요가 없습니다. 필요한 선수 개념과 전환 문장이 빠진 **설명 구조의 문제도 함께 있었습니다.**

## 이해 수준을 확인하는 여섯 질문

1. 한 사람의 FI=0.25와 집단 노쇠 비율 25%는 어떻게 다른가?
2. BMI=26.7과 ‘과체중’은 어떤 정보 차이가 있는가?
3. 노쇠 20명·비노쇠 80명에서 확률과 오즈는 각각 얼마인가?
4. 로그변환과 공변량 보정은 무엇이 다른가?
5. Q4/Q1 OR=1.73은 왜 FI가 73% 높다는 뜻이 아닌가?
6. 13,507명이라는 표본 수로도 시간 순서를 알 수 없는 이유는 무엇인가?

<details><summary>답의 핵심 확인</summary><p>1: 개인의 결손 비율 대 집단의 분류 비율. 2: 정확한 수치 대 구간 소속. 3: 0.20과 0.25. 4: X의 척도 변경 대 C를 함께 넣는 비교 조건 조정. 5: 결과는 FI 점수가 아니라 노쇠 여부의 오즈. 6: 서로 다른 사람을 많이 측정해도 같은 사람의 선후 변화가 생기지 않음.</p></details>

## HTML과 Obsidian을 비교할 관찰 기준

HTML은 순서대로 따라가기와 FI·오즈의 값 조절에, Obsidian은 개념 간 이동·본인 메모·백링크에 초점을 맞춥니다. 같은 03·06·08단계를 두 형식으로 읽고 **길을 잃는 횟수, 원문으로 돌아가기 쉬운 정도, 내 말로 설명 가능한 정도**를 비교해 보세요. 읽는 속도만으로 이해도를 판정하지 않습니다.
