> 논문 사실: 수정된 36항목 FI를 사용하고 FI>0.3을 노쇠, FI≤0.3을 비노쇠로 분류했습니다.

### 논문의 질문에 맞춰 왜 FI를 선택했나?

원문 Background 마지막 단락은 기존 연구들이 주로 Fried의 신체적 표현형을 사용한 데 비해, 이 연구는 **노화에 따른 결손 누적을 더 폭넓게 포착하기 위해 Rockwood의 다차원적 접근을 채택했다**고 설명합니다. 따라서 Fried 기준은 추가 지식으로 따로 붙이는 항목이 아니라, 이 논문이 Y의 측정법을 선택한 이유를 이해하기 위한 비교 대상입니다. [원문 PDF 2쪽, Background 마지막 단락](assets/paper.pdf#page=2).

저자의 선택 이유와 그 선택의 우수성 입증은 구별해야 합니다. 이 연구가 동일 표본에서 Fried와 FI를 직접 비교해 FI가 더 우수하다고 검증한 것은 아닙니다. Fried 측정이 불가능해서 FI를 썼다고 단정할 근거도 본문에 없습니다.

### 측정법 선택에서 회귀 질문까지

| 결정 | 이 논문의 선택 | 뒤 분석에 미치는 영향 |
|---|---|---|
| 무엇을 노쇠로 볼 것인가 | 여러 영역의 건강 결손 누적 | Fried의 5개 신체 항목과 다른 자료를 사용 |
| 어떻게 점수화할 것인가 | 수정 36항목 FI | 개인별 결손 정도를 표현 |
| 어떤 결과를 모형화할 것인가 | FI>0.3인 노쇠 여부 | Y가 0/1인 이진 결과가 됨 |
| 무엇과의 관계인가 | CBC 기반 지표 X | 지표 변화에 따른 노쇠 오즈를 추정 |
| 다른 특성은 어떻게 고려할 것인가 | Model 1·2 공변량 보정 | 선택한 조건 아래 OR와 95% CI 산출 |

따라서 논문의 OR는 **‘FI로 정의한 노쇠’와의 연관성**입니다. Fried로 정의한 노쇠에 대한 OR라고 바꾸어 읽을 수 없습니다.

### 실제 포함한 항목

기존 46항목 중 섭취·영양 관련 10개를 제외했습니다. 보충표 S1에 제시된 36항목은 다음 두 묶음입니다.

| 구성 | 항목 수 | 예 |
|---|---:|---|
| 자기보고 | 25 | 협심증, 심근경색, 뇌졸중, 당뇨, 기억 문제, 옷 입기·물건 들기 어려움, 건강 자기평가, 입원·약물 관련 항목 |
| 검사·측정 | 11 | 맥박, 수축기혈압, 맥압, 혈소판, 혈중 요소질소, 중탄산염, 적혈구 분포폭, LDH, ALP, 요산, 총칼슘 |

본문은 항목에 해당하면 1, 아니면 0으로 점수를 부여한다고 설명합니다. 표준적인 FI 계산은 평가 항목 대비 결손 비율이지만, **이 논문 본문만으로 부분 결측 시 분모 처리와 모든 항목의 세부 코딩을 완전히 복원하기는 어렵습니다.** 보충표는 항목 목록과 일부 검사 기준을 제공합니다. 학습용 36항목 완전관측 예시는 실제 결측 처리 규칙을 대신하지 않습니다.

### 0.3의 근거는 얼마나 제시되어 있나?

저자들은 수정 FI가 기존 NHANES 연구에서 사용·검증된 지수라고 인용하지만, 본 연구에서 0.3을 최적값으로 선정한 과정이나 여러 기준을 비교한 성능 분석을 제시하지 않습니다. 따라서 **사용 가능한 조작적 정의이지만, 이 자료에서 최선의 기준이라는 증거까지 확보된 것은 아닙니다.** 다른 FI 연구의 기준도 동일하지 않습니다.

최종 분석에서 비노쇠 9,778명, 노쇠 3,729명입니다. 이 둘을 구분하는 Y를 로지스틱 회귀에 넣었습니다. 논문 제목이 ‘frailty index’라고 되어 있어도, Table 2의 OR는 FI 점수 자체가 얼마나 증가하는지를 뜻하지 않습니다.

### 제가 권하는 보완 분석 — 논문이 수행했다고 보고한 것은 아님

- FI>0.30과 다른 사전 근거 있는 기준을 적용했을 때 결과가 어떻게 달라지는지 비교합니다.
- FI의 0–1 범위와 분포에 맞는 점수 모형을 검토합니다. 예를 들어 fractional logit 등을 고려할 수 있으며, beta regression은 0·1 끝값 처리 조건을 확인해야 합니다.
- SII에는 혈소판이 사용되고 FI에도 혈소판 항목이 있으므로, 해당 항목을 제외한 FI로 결과가 유지되는지 점검합니다.

이 제안들은 이분화를 ‘오류’로 단정하려는 것이 아니라, **분석 결론이 노쇠 정의에 얼마나 의존하는지** 확인하기 위한 것입니다.

원문은 한계에서도 FI만으로 노쇠를 정의했다는 점을 지적하며, 향후 Fried phenotype을 사용해 관계를 검토할 필요를 언급합니다. 즉 **측정법 선택 → 이 연구가 답하는 범위 → 다른 정의에서의 추가 검증**이 연결됩니다. Fried 기준으로 다시 분석하려면 필요한 항목을 확보해 Y를 새로 정의하고 회귀를 다시 적합해야 합니다. [원문 PDF 9쪽, 한계](assets/paper.pdf#page=9).

근거: [원문 PDF 2쪽](assets/paper.pdf#page=2), [보충표 S1](assets/supplement.docx).

현재까지 각 사람의 X와 Y를 만들었습니다. 이제 어떤 사람의 행을 분석에 포함할지, 어떤 빈칸이 남아 있는지 확인합니다.

### 후속 실행: 남은 논문 분석까지 구현

**발견한 문제:** 50–59세의 일부는 건강상 활동 제한이 없다는 선별 응답 때문에 세부 기능 문항을 질문받지 않았습니다. 공식 PFQ의 정확한 분기 조건과 원 항목의 시스템 결측을 확인한 경우에만 9개 기능 항목의 결핍값을 0으로 재구성했습니다. 답변 거부·모름·활동하지 않음 코드는 채우지 않았습니다.

독립 계산에서 4,992명·44,928개 항목이 재구성됐고, FI 완비 인원은 9,814명에서 13,289명으로 늘었습니다. 이전 완비 대상자의 FI는 동일했습니다. 이 규칙을 저자의 실제 코드라고 확인한 것은 아닙니다.

| FI 후보              | 인원    | FI=0 | FI=1 | 고유 점수 수 |
| ------------------ | ----- | ---- | ---- | ------- |
| FI_candidate36     | 9814  | 272  | 0    | 26      |
| FI_candidate36_alt | 13355 | 191  | 0    | 26      |
| FI_route           | 13289 | 894  | 0    | 26      |
| FI30               | 16885 | 356  | 0    | 147     |
|                    |       |      |      |         |

**Beta regression 질문:** FI=0이 실제로 있으므로 표준 beta regression을 전체 자료에 그대로 적합할 수 없습니다. 0을 임의로 밀어 넣거나 삭제하지 않았습니다. 기존 fractional logit은 경계값을 포함한 평균 FI라는 별도 질문의 구현으로 유지합니다. FI30은 관측항목 최소30개의 별도 분모 민감도이며 저자 FI가 아닙니다. [경계값 점검](assets/V3-20260928T003525Z/endpoint_audit.csv) · [독립 PFQ 재구성 검증](assets/V3-20260928T003525Z/expected_pfqqa.json)

### 구현·검토: 원문 FI와 재구성 후보를 구별하기

**확인한 것:** 본문과 부록 S1에서 36항목과 검사 범위를 확인했습니다. 직접 인용한 선행논문의 부록까지 조사했지만 설문 이분화·허용 결측·분모 규칙을 모두 찾지는 못했습니다. Fried의 5개 신체 표현형 기준은 여기서 FI를 계산하는 대체 코드가 아닙니다. 이 분석의 결과변수는 결핍 누적 FI입니다.

**고정한 구현 가정:** 예/아니오는 1/0, 기능곤란은 없음=0·조금/많이/불가능=1, 활동을 하지 않음·검사 누락·응답 거절은 결측으로 뒀습니다. 주관적 건강은 fair/poor, 처방약은 5개 이상, 의료 이용은 6회 이상을 결핍으로 정했습니다. 이 임계값은 저자에게 확인된 기준이 아닙니다. 정상 검사 범위의 양 끝은 정상에 포함했습니다. 전체 규칙은 [FI 설정](assets/analysis-20260928/config/fi_candidate.json)에 있습니다.

**왜 36항목 완비인가:** 저자의 부분결측 분모를 알 수 없어 후보에서는 36개 모두 관측된 경우에만 합/36을 계산했습니다. 임의 분모 축소를 피하는 재구성 선택이지만, 완전사례만 남기는 것이 편향을 없애는 것은 아닙니다. 실제 선택의 영향은 [[04-paper 04 표본 선정과 단면자료의 한계|04-paper]]에서 확인합니다. 초기 조사 의료이용 범주 ‘4–9회’는 6회 이상인지 알 수 없어 결측 처리했습니다. 범주 코드 3을 실제 방문 3회로 읽지 않았습니다.

**규칙 변경을 실험한 결과:** 같은 9,814명에서 건강 상태 경계를 한 단계 넓히고, 약물을 4개 이상·의료이용을 4회 이상으로 변경했습니다. 평균 FI는 0.1853→0.1995, FI>0.3 인원은 1,923→2,173입니다. 250명의 이진 분류와 1,412명의 사분위군이 달라졌습니다. 세 규칙을 함께 바꿨으므로 어느 한 규칙의 단독 효과라고 말하지 않습니다.

[같은 사람 코딩 민감도 결과](assets/analysis-20260928/runs/A03-coding/same_people_summary.csv) · [군 이동표](assets/analysis-20260928/runs/A03-coding/group_transition_same_people.csv) · [변경 규칙 군 비교](assets/analysis-20260928/runs/A03-coding/alternative_same_people/primary.csv)

0.3의 임상적 최적성을 이 자료의 p값으로 결정하지 않았습니다. 0.20·0.25·0.30·0.35의 민감도는 [[10-paper 10 Figure를 통해 결론의 범위 정하기|10-paper]], 연속 FI를 유지한 모형은 [[08-paper 08 Table 2의 Model 1과 Model 2|08-paper]]에 연결합니다.

## 4. 논문과 비교하면 어디까지 일치하는가

원문 36항목·FI>0.3은 확인했습니다. 후보의 fair/poor·약5개·방문6회·36완비 규칙은 확인된 저자 규칙이 아니므로 수치 재현의 전제는 미해결입니다. Fried 기준을 FI 대신 적용한 것도 아닙니다.
