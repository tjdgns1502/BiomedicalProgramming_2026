## Priority 4: fractional/beta applicability and reuse

Reuse the existing survey fractional logit. Its estimand is E(FI|marker,covariates), not Pr(FI>.30). exp(beta) is a ratio of conditional mean odds, not binary frailty OR. Retain original prediction contrast and label its existing absence of uncertainty. If adding uncertainty, use a design-consistent delta method or valid survey replicate design for standardized weighted mean FI difference at frozen exposure25th/75th percentiles. Model2 fractional extension is optional after priority1 and belongs to a new four-marker exploratory family, not the old32 family.

Tabulate min/max, count FI=0,FI=1 and number of distinct values for each candidate before any beta decision. Fractional quasi-binomial accepts endpoints and does not require a continuous beta response. Ordinary beta regression requires0<FI<1; strict FI is a finite grid of multiples1/36, so beta can be an approximation, not impossible by definition. Do not squeeze endpoints by a sample-size formula or drop them silently. If endpoints exist, stop the ordinary-beta branch only, recording why; zero/one-inflated beta is a different mixture estimand requiring another planned model. If no endpoints, beta remains optional because survey-design variance and bounded discrete-response assumptions need a defensible implementation. No beta fit is necessary to complete the user-facing comparison when fractional logit already answers the declared mean-FI question.
