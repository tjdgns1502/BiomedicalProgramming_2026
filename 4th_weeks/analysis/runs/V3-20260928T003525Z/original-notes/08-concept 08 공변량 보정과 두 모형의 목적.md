# 08 공변량 보정과 두 모형의 목적

[[00-start 처음부터 따라가는 분석 흐름|전체 흐름]] · [[08-paper 08 Table 2의 Model 1과 Model 2|논문에 적용하기]]

> 들어오는 자료: log(X), Y, C → 나오는 결과: 선택한 공변량을 함께 고려한 OR와 신뢰구간.

## 왜 염증과 노쇠만 비교하면 부족할까?

예시의 고령자에게 NLR와 FI가 함께 높다면, 연령이 두 값과 관련되어 있을 수 있습니다. **교란요인**은 관심 관계를 해석할 때 함께 고려해야 할 원인 구조의 일부입니다. 공변량은 모형에 넣은 변수라는 넓은 이름이며, 모든 공변량이 자동으로 진짜 교란요인인 것은 아닙니다.

```mermaid
flowchart LR
 A["연령"] --> X["염증지표 X"]
 A --> Y["노쇠 Y"]
 X -. "조사하려는 관계" .-> Y
```

위는 연령이 교란할 수 있다는 **설명용 인과 가정 도식**입니다. 이 논문에서 화살표를 실험적으로 증명했다는 뜻은 아닙니다.

## 보정은 값을 지우거나 빼는 작업인가?

NLR에서 나이를 빼지 않습니다. `로그오즈=β0+β1 log(NLR)+γ1 나이+γ2 성별+…`처럼 모형에 함께 넣습니다. β1은 그 모형 아래 다른 공변량이 같은 조건에서 NLR가 다른 경우를 비교하는 계수입니다. 실제로 모든 특성이 같은 사람을 짝지은 매칭을 했다는 뜻도 아닙니다.

범주형 공변량은 기준 범주와 비교하는 표시변수로 표현합니다. 예를 들어 BMI 세 범주는 ‘과체중 여부’, ‘비만 여부’ 두 열로 만들고 정상 범주를 기준으로 둘 수 있습니다. 정상=1·과체중=2·비만=3을 무조건 같은 간격의 숫자로 취급하는 것과 다릅니다.

## Model 1과 Model 2는 무엇이 다른가?

Model 1에는 기본 보정변수, Model 2에는 더 넓은 보정변수 집합을 넣습니다. 이때 **관심 X와 결과 Y는 유지하고 비교 조건을 바꿉니다.** 모델별로 원자료에서 계수를 다시 추정합니다. 두 번 계산해서 결과가 더 참이 되는 구조가 아닙니다.

결과가 비슷하면 선택한 보정 집합에 대해 관계가 비교적 안정적이라고 볼 수 있습니다. 달라지면 추가 변수와 관련된 차이, 표본 변화, 모형 구조 등을 살펴봅니다. 더 많이 보정할수록 무조건 더 좋은 모형은 아닙니다.

## 보정할 변수도 선택이 필요하다

원인 경로 중간의 변수(매개변수), 결과를 구성하는 항목, 공통 결과인 충돌변수 등을 무턱대고 넣으면 원하는 효과와 다른 것을 추정하거나 편향을 만들 수 있습니다. Table 1에서 p<0.05인 변수만 자동으로 골라 넣는 절차도 교란 통제를 보장하지 않습니다. 연구 질문과 시간·인과 구조가 먼저입니다.

<details><summary>심화: OR가 줄어든 만큼을 ‘제거된 교란의 양’이라고 할 수 있나?</summary><p>그렇게 단순 계산하면 안 됩니다. OR는 비축약성(non-collapsibility)이 있어, 교란이 없는 경우에도 공변량을 조건으로 한 OR와 전체를 합친 OR가 달라질 수 있습니다. 여기에 모형별 결측으로 분석 표본까지 달라지면 비교가 더 복잡해집니다. 핵심은 ‘변화=교란 제거량’이라는 등식이 성립하지 않는다는 점입니다.</p></details>

심화 근거: [OR의 비축약성과 교란 비교 연구](https://pubmed.ncbi.nlm.nih.gov/34225653/).

이제 같은 X·Y를 사용해 이 논문의 두 보정 모형을 나란히 읽을 준비가 되었습니다.
