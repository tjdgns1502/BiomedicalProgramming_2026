# 07 논문이 한 전처리와 보고하지 않은 점검

<!-- V2-LEARNING-STAGE-07 -->

> 읽는 순서: **논문 설명 → 남긴 의문 → 구현 → 재현 비교 → 추가 검토 → 갱신된 해석**. 개념이 막히면 위 통계 개념 노트로 돌아가세요.

## 1. 처음의 논문 설명과 데이터 흐름

> 아래는 구현 전에 작성한 원문 해설입니다. 당시의 미실행 설명은 이 구역의 작성 시점을 뜻하며, 이후 실제 실행 상태는 3–6구역에서 확인합니다.

[[00-start 처음부터 따라가는 분석 흐름|전체 흐름]] · [[07-concept 07 로그변환과 로지스틱의 가정|통계 개념 배우기]]

> 논문 사실: 네 지표의 비정규분포를 이유로 로그변환했습니다. 하지만 정규분포는 로지스틱 회귀의 필수 전제가 아닙니다.

### 저자의 설명을 그대로 확인한 뒤 평가한다

본문은 NLR·MLR·SIRI·SII가 비정규분포라서 분석 전에 로그변환했다고 기술합니다. 이 작업은 큰 값의 영향과 척도를 조정하는 데 도움이 될 수 있습니다. 그러나 **비정규분포라는 사실만으로 로그변환이 반드시 필요한 것은 아니며**, 변환 후 관계의 형태와 모형 적합성을 따로 봐야 합니다.

| 절차 | 논문에서 확인한 내용 | 같은 뜻이 아닌 것 |
|---|---|---|
| 지표 계산 | 혈구 수의 비·곱으로 구성 | 직접 측정한 CRP와 동일한 측정 |
| 로그변환 | 비정규분포를 이유로 사용 | 정규성 확보 또는 교란 제거를 보장 |
| 범주 코딩 | BMI·교육·생활습관 등을 범주화 | 범주가 원래 연속정보를 모두 보존 |
| 에너지 섭취 | 2일 평균 | 장기 섭취량을 완벽히 측정 |
| 결측 관련 제외 | 표본 선정 과정에서 보고 | 모든 최종 모형의 완전사례 처리 확정 |
| RCS | 비선형 항을 넣은 모형과 직선 모형 비교 | 로그변환만으로 곡선 문제 해결 |

### 재현 시 확인해야 할 미보고 사항

설명변수 로그의 밑, 0·극단값 처리, 변환 전후 분포 진단, 공선성 진단, 회귀 수렴·분리 점검, 모든 모형의 복합표본 설계 설정은 원문만으로 충분히 알기 어렵습니다. **보고되지 않았다는 것과 수행하지 않았다는 것은 다릅니다.** 이 자료에서는 ‘확인 불가’로 표시합니다.

자료 규모가 13,507명이라는 사실은 작은 표본보다 정밀도에 유리하지만 잘못된 척도, 결측 선택, 설명변수 중복 같은 문제를 자동으로 해결하지 않습니다.

### 다음 분석에 넘기는 것

이 단계의 산출물은 각 사람의 `log(X)`, `Y`, 코딩한 `C`가 있는 분석 표입니다. 아직 Model 1의 OR를 변환해 Model 2를 만드는 것이 아닙니다. 다음 단계에서 이 표를 사용해 서로 다른 공변량 집합의 모형을 **각각 적합**합니다.

근거: [원문 Statistical analysis, PDF 3쪽](assets/paper.pdf#page=3).

## 2. 이 단계에서 남겨 둔 의문

**연속 로그 지표와 logit의 직선 관계가 적절한가?**

설명변수의 정규성 대신 결과와의 함수 관계를 확인한다. 고정 df3 자연스플라인의 추가2자유도를 검정한다.

## 3. 어떻게 구현했고 무엇을 얻었나

**새 구현:** 같은 후보 표본에서 `logit(p)=선형 로그 지표+공변량`과 추가 비선형 2항이 있는 모형을 비교했습니다.

| 지표 | 비선형 원 p | 4개 Bonferroni p | 분자/분모 자유도 |
|---|---|---|---|
| NLR | 3.5e-10 | 1.4e-09 | 2/138 |
| MLR | 3.65e-09 | 1.46e-08 | 2/138 |
| SIRI | 4.71e-06 | 1.88e-05 | 2/138 |
| SII | 2.03e-09 | 8.11e-09 | 2/138 |

자연로그 지표의 고정 1/3·2/3 분위수 knot와 df3 자연스플라인을 사용하고, 선형 부분 밖의 두 항을 설계 기반 Wald F로 검정했습니다. Bonferroni의 검정 가족은 사전에 정한 네 지표입니다. 유의하지 않다고 선형성이 증명되는 것은 아닙니다. [진단 전체 수치](assets/V2-20260927T235327Z/nonlinearity_tests.csv)

**결과를 읽으면:** 네 지표 모두 Bonferroni 보정 후에도 p<0.05였습니다. 이 후보 자료와 고정한 모형에서는 로그 지표와 로그오즈의 관계를 직선 하나로만 표현하기 부족하다는 근거입니다. 스플라인이 다른 집단에서도 더 잘 예측하거나 생물학적으로 참이라는 결론은 아닙니다.

## 4. 논문과 비교하면 어디까지 일치하는가

원문의 로그변환은 확인됐습니다. 여기서 사용한 knot·df·검정 가족은 분석자의 사전 고정 진단입니다. 새 진단을 원문 RCS와 동일하게 구현했다고 표기하지 않습니다.

## 5. 의문을 검토한 과정과 추가 분석

### 실행·진단: 정규성·이분산·영향점을 따로 확인하기

**전처리 검증:** XPT의 0이 Python 판독에서 약 5.4×10⁻⁷⁹로 읽히는 문제를 발견했습니다. 정확한 해당 표현만 0으로 복구하고 R의 별도 판독기와 6개 파일 268,632개 값을 비교했습니다. 수치와 0 분류가 일치했습니다. 원본 XPT는 보존했습니다. [대조 기록](assets/analysis-20260928/runs/S02-nhanes-data/xpt_zero_crosscheck.json)

**아래는 ANOVA의 진단입니다. 로지스틱의 정규성 검사가 아닙니다.**

![NLR ANOVA의 네 가지 잔차 진단](assets/analysis-20260928/runs/A01-groups/diagnostics_NLR.png)

| 그림 | 확인하는 질문 | 이번 해석 |
|---|---|---|
| 잔차–적합값 | 군 평균 주변의 퍼짐이 같은가 | 네 군이므로 적합값이 네 위치에 모임 |
| Q–Q | 잔차 꼬리가 정규분포와 비슷한가 | 오른쪽 꼬리의 큰 이탈 확인 |
| Scale–Location | 표준화 잔차 퍼짐이 적합값에 따라 달라지는가 | 등분산을 무조건 전제하기 어려움 |
| 잔차–레버리지 | 일부 행이 추정에 큰 영향을 줄 가능성이 있는가 | 큰 잔차는 조사 대상이며 자동 삭제 사유가 아님 |

MLR·SIRI·SII에도 동일한 네 진단을 생성했습니다: [MLR](assets/analysis-20260928/runs/A01-groups/diagnostics_MLR.png), [SIRI](assets/analysis-20260928/runs/A01-groups/diagnostics_SIRI.png), [SII](assets/analysis-20260928/runs/A01-groups/diagnostics_SII.png).

로지스틱은 설명변수의 정규분포를 요구하지 않습니다. 대신 평균 구조의 적절성, 연속 설명변수와 logit의 형태, 표본 설계, 분리 현상과 수렴을 확인해야 합니다. 이번 모형은 수렴을 확인하고 설계 기반 표준오차를 사용했지만, 모든 비선형성·잔여 교란을 해소했다고 주장하지 않습니다. Welch도 심한 왜도에서 언제나 정확한 유의수준을 보장하지 않습니다. 실제 검정 코어를 대상으로 한 모의실험은 [[10-paper 10 Figure를 통해 결론의 범위 정하기|10-paper]]에 있습니다.

## 6. 갱신된 해석과 남은 한계

**현재 판정: 부분 해결 — 계산·진단은 수행했으나 저자 미공개 정의는 남음**

이 진단은 분석자가 정한 모형이다. 원문 RCS knot·기준점이 확인된 재현은 아니다.

새 계산은 독립 계획 검토 후 실행하고 별도 결과 검토를 거쳤습니다. 과거 자료·모형의 재사용 감사는 입력과 코드의 일관성을 확인한 것이며, 저자 FI 정의나 인과적 해석의 인증이 아닙니다.
