# 05 Table 1을 읽는 순서

[[00-start 처음부터 따라가는 분석 흐름|전체 흐름]] · [[05-concept 05 중앙값·IQR·빈도·비율 직접 계산|통계 개념 배우기]]

> 논문 적용: Table 1은 전체·비노쇠·노쇠 집단의 특성을 요약하고 비교합니다.

## 한 줄씩 읽는다

| Table 1의 항목 | 실제 보고값 | 읽는 방법 |
|---|---|---|
| 전체 연령 | 66 (61, 74) | 중앙값 66세, P25=61세, P75=74세 |
| 전체 남성 | 6,722 (46%) | 실제 표본의 인원과 보고된 비율 |
| 전체 NLR | 2.14 (1.60, 2.88) | NLR 중앙값과 가운데 구간 |
| 비노쇠 NLR | 2.08 (1.57, 2.78) | FI≤0.3인 사람들의 요약 |
| 노쇠 NLR | 2.35 (1.70, 3.23) | FI>0.3인 사람들의 요약 |

전체 NLR 중앙값은 Results 본문의 2.08과 Table 1의 2.14가 다릅니다. 가중·비가중 요약 차이일 가능성은 있으나 원문이 분명히 설명하지 않으므로 여기서는 **Table 1의 값을 그대로 읽습니다.** 두 값을 임의로 같은 것처럼 취급하지 않습니다.

## 인원을 나눈 값과 퍼센트가 왜 다르지?

3,729/13,507≈27.6%인데 표는 노쇠 24%를 보고합니다. 남성도 6,722/13,507≈49.8%인데 46%입니다. 조사 가중치를 적용하면 각 사람이 대표하는 인구 수가 달라져 단순 인원 비율과 달라질 수 있습니다.

예를 들어 A가 100명, B가 300명을 대표하고 B만 노쇠라면 표본 비율은 1/2=50%지만 가중 비율은 300/400=75%입니다. 이것은 **계산 원리의 가상 예시**입니다. 논문 표는 가중 분석을 시사하지만 각주에 모순된 표기가 있어 정확한 구현을 확정하지는 않습니다.

## p값은 다음 질문에 답한다

본문은 연속형에 분포에 따라 t 검정 또는 Mann–Whitney U 검정, 범주형에 카이제곱 검정을 기술합니다. Table 1의 더 구체적인 각주는 복합표본용 Wilcoxon 순위합 검정과 Rao–Scott 보정 카이제곱 검정입니다.

이는 ‘두 집단의 분포·비율 차이가 우연 변동만으로 설명되기 어려운가’를 묻습니다. 순위합 검정은 일반적으로 **분포 비교**이며 항상 중앙값만의 검정이라고 단정하지 않습니다. 또한 p<0.001이라고 차이가 임상적으로 크거나 염증이 원인이라는 뜻은 아닙니다.

본문은 노쇠군 림프구도 유의하게 높다고 서술하지만 Table 1의 림프구 p값은 0.229입니다. 결과 해석은 실제 표와 대조해야 합니다.

## 구현·검토: Table 1의 요약을 실제 행에서 계산하기

**논문 표의 복사와 구분:** 다음은 재구성 후보 자료의 기술통계입니다. 원문 Table 1을 재현했다는 표시는 하지 않습니다. 과제에 맞춰 **FI군별 NLR**을 요약합니다.

| FI군 | 유효 인원 | 평균 | 중앙값 | Q1–Q3 (중간 50%) |
|---|---|---|---|---|
| Q1 | 2,761 | 2.095 | 1.917 | 1.455–2.500 |
| Q2 | 2,832 | 2.248 | 2.044 | 1.500–2.737 |
| Q3 | 1,824 | 2.413 | 2.096 | 1.583–2.930 |
| Q4 | 2,369 | 2.693 | 2.273 | 1.615–3.200 |

예를 들어 Q1군 NLR 중앙값 1.917는 값의 가운데 위치입니다. 표의 1.455–2.500는 가운데 50%의 구간이며, IQR의 **폭**은 1.045입니다. 이것을 평균의 신뢰구간으로 해석하지 않습니다. 평균이 중앙값보다 큰 모습은 오른쪽 꼬리의 영향을 함께 보게 합니다.

**인구 비율이 달라지는 계산:** 후보 FI 완비 여성은 4,861/9,814=49.53%입니다. 그러나 각 사람이 대표하는 인원에 MEC 가중치를 곱한 여성 비율은 53.71%입니다. 전자는 관측된 사람 수의 비율, 후자는 조사 설계 가중 비율입니다. 수치가 다른 것 자체가 오류는 아니며, 가중 비율에도 완전사례 선택 한계가 남습니다.
