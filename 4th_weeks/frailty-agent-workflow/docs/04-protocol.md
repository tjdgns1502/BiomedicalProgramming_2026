# 분석 설정과 검정 계획을 고정하는 방법

## 공통 데이터 계획

원자료가 교수 제공 자료인지 NHANES 직접 구축 자료인지 먼저 확인합니다. 제공된 FI만 있는 자료와 36개 항목까지 있는 자료는 검증 범위가 다릅니다. 원자료는 읽기 전용으로 보존하고 파일 해시·접근일·주기·코드북·R 및 패키지 버전을 기록합니다.

전처리의 정당성은 논문값과 가까워졌는지가 아니라 변수 정의·자료 품질·연구 대상에 대한 근거로 판단합니다. NHANES 복합표본 추론과 비가중 교육 실습을 같은 분석으로 보고하지 않습니다. 가중치 통합은 측정 항목의 하위표본·주기별 지침을 확인한 뒤 확정합니다.

## A: 재현 설정에 대한 가설

예: ‘Table 1 비율 차이는 조사 가중치 때문일 수 있다.’

1. 원문 제목·각주·인원수·비율의 충돌을 기록합니다.
2. 미보고 설정의 후보와 후보가 가능한 근거를 등록합니다. 가중/비가중, 결측 범주, log 밑 등이 후보입니다. 정당화되지 않은 행 삭제는 후보로 허용하지 않습니다.
3. 후보 조합, 출력별 허용 오차와 최대 실행 횟수를 실행 전에 정합니다. 단위가 다른 값을 그대로 더한 단일 점수나 p값만의 일치를 쓰지 않습니다. N은 정수 일치, 반올림된 요약값은 표시 자릿수, 계수와 CI는 별도 기준으로 비교합니다.
4. 성공·실패·수렴 실패를 모두 저장합니다. 추가 후보는 변경 이유와 시점을 남깁니다.
5. 같은 출력에 맞는 여러 설정이 있으면 모두 식별 가능한 후보로 남깁니다. 출력 일치만으로 저자의 실제 코드를 확정하지 않습니다.
6. 예산 소진·후보 소진·증거 부족이면 오차와 미해결 원인을 보고합니다. 더 작은 오차를 위해 탐색을 무한 반복하지 않습니다.

추천 초기 운영 상한은 근거 있는 설정 조합 12개입니다. 이는 통계적 정리가 아니라 범위 통제를 위한 제안입니다. 늘리려면 로그에 남깁니다. 이미 본 논문 수치를 확인용으로 남겨도 독립 검증이라고 부르지 않습니다.

## B/C: 과제의 통계적 가설

| 결정 | 고정할 내용 |
|---|---|
| 분석 단위 | 참여자 한 명; 중복 및 주기별 병합 확인 |
| 군 | FI 사분위; 가중 여부·분위수 알고리즘·동점·경계 포함 규칙 |
| 결과 | NLR·MLR·SIRI·SII 각각; 원단위 또는 log 척도 |
| 추정 대상 | 산술평균 차이 / log 평균 차이 / 순위·분포 차이를 구별 |
| 주 검정 | 연구 질문과 오차 구조에 따라 선택; 최소 p값으로 선택하지 않음 |
| 비교 방법 | 세 검정은 과제에서 모두 구현하되 주/보완 분석 라벨 부여 |
| 사후검정 | 표준 ANOVA–Tukey; Welch·순위 접근에는 맞는 비교법 |
| 경향성 | 1·2·3·4 또는 군별 FI 중앙값 등 점수와 표준오차 방식 |
| 결측 | 군 경계의 기준집단과 지표별 분석 인원; 완전사례와 대치의 조건 |
| 보고 | 차이·CI·원 p값·보정 p값·n·한계 |

정규성 검정 하나로 방법을 자동 분기하지 않습니다. log 변환 후 결과는 원척도의 산술평균 차이와 추정 대상이 다릅니다. Welch는 등분산 가정을 완화하지만 표본의 군집성까지 해결하지 않습니다. Kruskal–Wallis는 추가적인 분포 모양 조건 없이 중앙값 검정이라고 단정하지 않습니다.

## 검정 가족

초기 제안은 `F_omnibus`=주 방법의 네 지표 전체 차이 검정, `F_trend`=네 지표의 사전 지정 경향 검정, `F_pairs`=주 쌍별 비교 절차의 24개 비교입니다. 이 구분은 서로 다른 주장 단위이며 세 가족 전체에 대한 오류 통제를 보장하지 않습니다. 보고서에서 모든 결과 중 하나라도 발견됐다는 전체 주장을 하려면 더 넓은 가족 또는 계층 절차를 정해야 합니다.

Tukey는 지표별 6개 비교의 동시 추론입니다. 네 지표 24개 전체가 Tukey 하나로 보정됐다고 쓰지 않습니다. Bonferroni/BH 비교는 같은 가족의 원 p값에 각각 적용하며, Tukey 보정 p값에 근거 없이 다시 BH를 적용하지 않습니다. 사후검정 실행을 전체 검정 유의성으로 제한한다면 모의실험에서도 그 선택 절차 전체를 반복합니다.

FWER와 FDR를 구별합니다. BH의 보장은 의존 구조의 조건에 따라 달라집니다. CBC 지표는 혈구 성분을 공유하므로 독립 가정이 자동 성립하지 않습니다.

## M: 방법 검증 시나리오

| 실험 | 생성 규칙 | 확인할 결과 |
|---|---|---|
| M01 독립 전역 귀무 | 군 차이 없는 독립 정규 자료에서 독립 검정 k개 | 원 p값 균등성, FWER와 1−0.95^k, MCSE |
| M02 의존 전역 귀무 | 같은 사람의 상관된 지표 또는 네 군의 공유 쌍별 비교 | 무보정·Bonferroni·BH 오류율; 독립 공식과 차이는 실패가 아님 |
| M03 혼합 귀무/대립 | 일부 지표에 알려진 효과, 나머지 영효과 | FDR·FWER·검정력 및 효과 크기별 변화 |
| 확장 진단 | 이분산·왜도·불균형 표본 | 가정 위반에서 방법 또는 선택 절차가 어떻게 작동하는지 |

독립·연속형 유효 검정의 전역 귀무에서만 FWER=1−(1−α)^k를 확인합니다. 실제 네 염증지표의 p값 4개로 균등성을 검증하지 않습니다. 이산·보수적 검정은 정확한 균등성이 아닐 수 있습니다.

FWER 반복 지표는 `I(V>0)`, FDP는 `V/max(R,1)`입니다. FDR는 FDP의 반복 평균입니다. 전역 귀무에서는 모든 발견이 거짓이므로 FDR=FWER이며, 혼합 시나리오가 두 목표를 구별하는 데 필요합니다.

반복 수 B에서 FWER의 MCSE는 `sqrt(p_hat*(1-p_hat)/B)`입니다. FDR의 MCSE는 반복별 FDP의 표준편차를 `sqrt(B)`로 나눕니다. 검정력도 무엇을 분모로 하는지 정합니다. 경계 0·1에서는 MCSE만 0으로 보고 확실하다고 단정하지 않고 이항 구간 등도 함께 봅니다.

`expand.grid()`로 n·k·분산비·의존성 조건을 만들고 `Map()`으로 시나리오 함수를 호출합니다. 큰 격자를 무작정 실행하지 않습니다. 초기 제안은 파일럿 B=1,000, 본 실행 B=10,000이며 목적 MCSE와 실행시간을 보고 사전에 조정합니다. seed는 시나리오별로 기록하고 병렬 실행에서는 독립 난수 스트림을 사용합니다. 기대 결과에 맞는 seed를 고르지 않습니다.

단일 실험에서 기준값이 한 번 구간 밖에 나왔다고 구현 오류를 확정하지 않습니다. 몬테카를로 구간·격자 전체의 우연 변동·독립성·검정 보정을 함께 확인합니다. 모의실험의 성공은 검증한 자료 생성 조건에 한정됩니다.
