# 완료 기준과 오염·실패 점검

## 현재 상태

이 패키지의 문서·작업 연결·패킷 생성 규칙을 검증합니다. 이는 과제의 통계 검증 완료가 아닙니다. 원자료 확인과 R 실행은 후속 작업으로 남습니다.

## 최종 보고서의 네 문장

1. **과제 분석:** 어느 자료·군 정의·추정 대상에서 어떤 차이가 관찰됐는가?
2. **논문 재현:** 어느 출력이 어느 후보 설정에서 얼마나 일치했으며 무엇이 미해결인가?
3. **방법 검증:** 어떤 자료 생성 조건에서 어떤 오류율·검정력·불확실성을 확인했는가?
4. **해석 한계:** 단면자료·측정 중복·결측·계획 변경·결과 노출 때문에 말할 수 없는 것은 무엇인가?

## 검수자가 잡아야 할 오류 예

- FI 사분위 과제를 염증지표 사분위 OR만으로 대체했다.
- 논문 목표 OR에 가까워졌다는 이유로 관측치를 삭제했다.
- FI 항목 목록만 확인하고 모든 코딩·분모 처리까지 재현했다고 썼다.
- 표본 가중치와 공변량 보정, 다중검정 보정을 같은 ‘보정’으로 취급했다.
- Welch 뒤에 표준 Tukey를 기계적으로 붙였다.
- raw p값과 이미 보정된 p값을 혼합해 BH를 적용했다.
- 공유 지표/쌍별 검정에 독립 공식 1−0.95^k를 그대로 정답으로 사용했다.
- 모의실험 자료를 실제 NHANES 결과로 보고했다.
- 같은 자료로 계획을 바꾼 뒤 독립 검증·사전등록이라고 주장했다.
- 출력 파일만 존재하고 실행 로그·버전·해시 또는 실제 그림이 없다.

## 학습자료를 갱신하는 시점

새 결과를 바로 기존 학습자료의 ‘논문 사실’에 덧붙이지 않습니다. G 검수 후 별도 ‘이번 과제에서 수행한 분석’으로 연결합니다. 원문 사실은 원문 근거로만 갱신하고, 추정 후보는 확정하지 않습니다. 사용자 메모가 있는 Obsidian 노트를 전체 재생성하지 않습니다.
