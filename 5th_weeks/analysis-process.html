DATA → INFERENCE

한 사람의 자료가 표와 OR가 되는 과정

개인 응답을 변수로 바꾸고, 포함 여부를 정한 뒤, 복합표본 설계를 반영해 집단의 연관을 추정합니다. 개인 한 명의 p값이나 OR를 만드는 과정은 아닙니다.

ASSIGNMENT EXTENSION

과제의 통계 원리는 어떻게 확인했나

V1은 실제 NHANES 복합표본 생성의 재현이 아니라, 정의한 교육용 표집·효과척도·짝지음 예제의 검증입니다.

Fisher: 정확 열거 + Monte Carlo

집단당 n=5·10·20·50, 귀무 공통 p=0.05·0.2·0.5에서 가능한 표를 열거했습니다. R의 양측 probability-ordering Fisher p<0.05 규칙을 사용하고 조건당 10,000회, seed 20261004로 확인했습니다. 정보 없는 표는 비기각으로 정했습니다.

예: n=5, p=0.5에서 실제 기각확률은 2.1484%입니다. 명목 5%보다 낮습니다. n=10/10·전체 성공 10으로 주변합을 고정한 조건부 기각확률은 2.3014%입니다. 서로 다른 조건을 섞지 않습니다.

OR와 PR: 같은 crude 표를 비교

출판 비가중 치주질환 표에서 노출군 고혈압 유병률은 53.34%, 비노출군은 49.89%입니다. crude OR=1.14835, PR=1.06922로 두 배수의 상대 차이는 약 7.40%입니다.

횡단면 결과이므로 PR은 유병률비입니다. “발생 위험이 7.4% 증가”라는 뜻도, adjusted OR를 RR로 바꾼 결과도 아닙니다.

과제 검증 전체 설명 ↗오류율·MC 불확실성 ↗crude OR·PR 계산 ↗

McNemar: 실제 자료 적용과 강의 예제를 구분

이 NHANES 분석에는 같은 사람의 전후 짝지음 구조가 없으므로 McNemar의 실자료 적용은 해당 없습니다. 가상 100명 표 (40, 25; 5, 30)의 불일치 쌍 25 대 5에서 정확 이항 p≈0.000324914를 검산했습니다. 이 값은 논문 고혈압 연관의 p값이 아닙니다.

확정하지 않은 것

“치주질환 치료가 고혈압을 예방한다”, “보정 후 교란·선정·결측 편향이 제거됐다”, “OR가 곧 RR이다”, “Fisher 결과가 모든 표집에서 같다”, “출판값에 가까운 모형이 더 타당하다”는 결론을 내리지 않습니다.

남은 의문을 풀려면 어떤 증거가 더 필요한가

  1. 저자 분석 코드·변수 목록·제외 흐름 — 혈압 평균, 약물 skip, 흡연·당뇨 문항, 결측 대체와 가중치의 정확한 설정을 확인해야 한다.

  3. 가정이 바뀌는 별도 분석 계획 — 결측·선정·측정 가정의 추가 민감도는 추정 대상과 평가 기준을 고정하고 새 run으로 수행해야 한다. 작은 p나 출판값 근접을 목적함수로 쓰지 않는다.
  4. 다른 자료·설계의 증거 — 외부 일반화나 인과 주장은 현재 자료의 수치 감사만으로 해결되지 않는다.
