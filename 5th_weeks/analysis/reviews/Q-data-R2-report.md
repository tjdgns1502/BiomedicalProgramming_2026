# R2 독립 자료 검토

검토 대상: `R2-20261004`, 자료 버전 `nhanes-2009-2018-7ad570c1e84a460b267c`. 판정과 정확한 해시는 `review.json`에 저장했다.

이 검토자는 논문 출처 확보를 맡았으며 발표된 수치도 보았다. 분석 구현자는 별도 에이전트이다. 구현 코드를 실행하거나 불러오지 않고, 공개 원시 XPT에서 별도로 참가자와 변수를 재구성한 내부 독립 자료 검토이다. 외부 검증이나 블라인드 검증으로 표현하지 않는다.

## 자료·선정·분할표

25개 원시 XPT와 25개 공식 코드북의 SHA256을 입력 목록과 대조한다. 원시자료의 SEQN 고유성을 확인하고, 각 조사주기 DEMO를 기준으로 OHQ/BPQ/BPX/SMQ를 독립적으로 결합한다. 원시값과 파생값을 완성된 master.rds와 참가자별로 대조한다. 원시파일은 수정하지 않는다.

## 정의 및 혈압 0 기록

OHQ835는 자기보고 치주질환으로 해석한다. OHQ845는 1·2를 excellent/very good으로 합치고 3/4/5를 good/fair/poor로 분류한다. SMQ020은 평생 100개비 이상 흡연 여부이며 현재 흡연 여부라는 명칭을 붙이면 안 된다.

BPQ050A의 건너뛰기를 단순 결측으로 처리하지 않는다. 진단 없음(BPQ020=2) 또는 처방 없음(BPQ040A=2)으로 질문이 구조적으로 생략된 경우 약 복용 없음으로 분류하는 구현을 원시값에서 독립적으로 확인했다. 양성 혈압·진단·복약 중 하나라도 관측되면 복합 고혈압=1, 모두 음성이 확인되어야 0으로 분류한다. 구조적 약 복용 없음 기록은 전체 22,673명이다.

분석은 유효한 BPXSY1–4 및 BPXDI1–4를 모두 평균내는 명시된 후보 정의이다. BPXDI의 0은 해당 과거 NHANES 원자료에서 가능한 기록이다. 그러나 CDC의 해당 시기 참가자 보고용 평균 규칙은 반복 측정이 있으면 첫 측정을 제외하며, 0 이완기 혈압과 양수 값이 혼재하면 0을 평균에서 제외한다. 모든 값이 0이면 평균 0이다. 따라서 현재 정의를 CDC의 그 평균 규칙과 동일하다고 표현하지 않는다.

원시 전체에서 이완기 0 기록이 있는 사람은 983명, 분석 대상에서는 271명이다. 양수 이완기 혈압과 혼재한 0만 제외하는 별도 민감도 계산에서 분석 대상의 측정 고혈압 및 복합 고혈압 분류 변화는 각각 0명이었다. 이 계산은 첫 측정 제외 규칙까지 구현한 결과가 아니다.
