# 선정 결측과 복합표본 — 이론

입력은 연결된 사람 행과 가중치·층·PSU입니다. 이번 질문은 누가 분석 분모에 포함되는가입니다. 2년 가중치가 W일 때 5개 동등한 주기 결합 가중치는 W/5입니다. 가중 합은 사람 수의 표본 n과 다르며 n 대신 보고하면 안 됩니다.

먼저 양의 MEC 가중치 전체로 survey design을 만들고 30세 이상·필수 측정·설문 응답의 부분모집단을 design에서 subset합니다. 가중치만 넣은 일반 glm은 층화·군집 분산을 반영하지 못합니다. 설계 기반 추론은 PSU와 층을 사용합니다.

결측 범주·지시변수는 누락을 기술하는 구현이며 교란 편향을 자동 해결하지 않습니다. complete case 분석은 다른 분석집단을 만들 수 있으므로 표본수와 해석이 달라집니다. 출력은 선정 flow, 결측 표, 분석집단 ID, 설계객체입니다. 상류 정의가 바뀌면 이 단계 아래 표·모형·그림·해석을 함께 다시 검토합니다.
