# 현재 상태

범위 내 정의 가능한 필수 작업 완료: 출처 확인, paired 학습노트, 공개원자료 QA, 본문/보충모형 후보, 검정과 그림, 독립 검토, 기존문서 통합.

재현 수준: 부분 재현. 선택 N와 숨은 저자 구현의 미확인은 식별불가로 기록. 실행 가능한 필수 항목을 미실행으로 남기지 않음.

현재 run: R2-20261004(core), E2-20261004(extended), V1-20261004(validation). R1 실패 보존. 원자료/자료정의 동일하나 다르게 가중·선정한 B/보충집단은 별도 표기.

optional common complete case: 초기 계획의 선택 항목, 실행하지 않음(deferred); 범주/연속결측 지시변수 한계는 판정에 포함.
