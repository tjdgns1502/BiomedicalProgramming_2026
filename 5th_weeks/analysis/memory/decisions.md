- 원본 경로 이동을 탐색으로 확인하고 발견한 v2.0 사본을 보존.
- 지정 PMID 일치 확인, 논문 변경 불필요.
- 자가보고 OHQ를 논문 기준선, 과제 통계 시뮬레이션을 assignment_extension으로 분리.
- 초안 age≥20를 실행 전 Q 지적으로 age≥30으로 정정(v1→v1.1). v1 결과는 존재하지 않음.

- Windows R 로케일 C.UTF-8 실패를 English_United States.utf8로 변경. 프로젝트 전용 패키지 사용.

- plan1.2→1.3: 독립 검토가 ALQ_J 3–4/week·monthly code와 SLD012 half-hour 처리 수정. 실행 전 반영, 이전 v1.2 수치 없음.
- A/B 최대2개 고정. 본문 Table3의 다른 조정변수, 보충표 결과 정의를 별도로 구현. 후보를 출판수치에 맞춰 추가하지 않음.

- plan1.3→1.4: 유효 보충PDF에서 보충모형 공변량은 본문과 다름을 확인. I1628/12411,II9389/20172와 같은 비고혈압10783에서 domain 분리 추론. 저자 코드 확인이 아닌 counts-supported inference. 실행 전 수정.
- 노출내역 정정: I/Q도 원문 Methods·각주 웹 응답에 결과 수치가 함께 표시되어 미노출 주장을 철회. 독립 인스턴스 감사이며 맹검으로 표현하지 않음. 수치 맞추기 수행 없음(I 자기보고).
- R1 실행실패: SAS XPT first160byte의 NUL을 문자열로 변환한 검증 오류. 코드 first80ASCIIheader/NULstrip 수정, 실패로그 불변보존; 새 R2에서 실행. 자료정의·표본 계획 변경은 아님.
