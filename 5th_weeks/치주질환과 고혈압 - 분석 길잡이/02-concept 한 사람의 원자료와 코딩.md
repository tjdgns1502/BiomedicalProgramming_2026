# 한 사람의 원자료와 코딩 — 이론

입력은 숫자 코드입니다. 숫자 1/2/7/9가 모두 양적 크기를 뜻하지 않습니다. 범주형 변수는 코드북의 응답 의미로 변환합니다. 예를 들어 yes=1, no=2, refused=7, don't know=9일 때 7/9를 no로 묶으면 결측을 정상으로 바꾸는 오류입니다.

가상 사람 A의 SBP가 138,142,140이면 평균은 140 mmHg입니다. 치주질환=Yes, 구강상태=Fair, 혈압 평균≥140이므로 고혈압=Yes입니다. 개인에게 연구 OR나 p값을 붙이지 않습니다. 개인 행이 집계와 회귀의 점수에 기여하고, 집단 수준에서 계수와 불확실성이 계산됩니다.

질문 건너뛰기(structural skip)는 무응답과 다릅니다. “고혈압 진단 없음” 때문에 약물 질문을 안 했다면 조건을 확인하여 약물 없음으로 해석할 수 있지만, 진단 refused 때문에 빠졌다면 알 수 없음입니다. 출력은 의미가 명확한 분석 열이며, 남은 질문은 평균·분기 규칙의 원문 공개 여부입니다.
