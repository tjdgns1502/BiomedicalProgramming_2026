# HR05 · CONCEPT — 잔차 진단, Q–Q, 영향점, 민감도의 의미

> 일반 통계 개념 페이지. 숫자는 모두 **🧪 가상 예제**. 실제 적용은 [HR05-paper](HR05-paper.md).

## 입력
HR03에서 적합한 OLS 모형과 잔차, HR04의 오차 요약.

## 이번 질문
"결과가 회귀 가정을 크게 어기지 않는가? 한두 사람이 결론을 좌우하는가?" 진단은 **결과를 고르려는** 것이 아니라 **결과를 얼마나 믿을지** 알려는 것이다.

## 방법과 이유

### 잔차 대 적합값 그림
가로 = 적합값, 세로 = 잔차. 0 주위에 고르게 퍼지면 좋다.
- 곡선 모양 → 직선 관계가 아님
- 깔때기 모양 → 등분산 위반
- 홀로 멀리 떨어진 점 → 이상치 후보

### 표준화 잔차와 Q–Q 그림
표준화 잔차 = 잔차 / (s·√(1 − hᵢ)). 대략 정규라면 |값| > 2는 20명 중 1명 정도로 드물다.
Q–Q 그림: 표준화 잔차를 크기순으로 놓고 정규분포 분위수와 짝지어 그린다. 직선 위에 있으면 정규에 가깝다. n = 22 정도에서는 우연히도 꼬리가 휘기 쉬워 **강한 결론을 내리지 않는다**.

### 레버리지와 Cook's distance
```
레버리지 hᵢ = 1/n + (xᵢ − x̄)² / Σ(x − x̄)²       x가 평균에서 멀수록 큼
Cook's Dᵢ = (eᵢ² / (p·s²)) · hᵢ / (1 − hᵢ)²      p = 계수 수(2)
```
Cook's D는 "i를 빼면 적합선이 얼마나 움직이나"를 한 숫자로 요약한다. 4/n 같은 기준선은 **경험칙**이지 검정이 아니다.
- 잔차가 커도 x가 가운데면(레버리지 작음) 선을 많이 못 움직인다.
- 잔차가 작아도 x가 끝에 있으면(레버리지 큼) 선을 끌어당길 수 있다.

### 한 명씩 제외(leave-one-out) 민감도
n번 다시 계산하며 매번 한 명을 뺀다.
🧪 시계 B 오차 +2, −2, +1, −1, 0에서 한 명씩 빼면 bias = −0.5, +0.5, −0.25, +0.25, 0 → **범위 −0.5 ~ +0.5**.
- 이 범위는 **신뢰구간이 아니다**(표본추출 확률 해석이 없음).
- **교차검증도 아니다**(새 사람에 대한 예측 성능을 재지 않음).
- "특정 한 사람이 결론을 뒤집는가"만 보여 준다.

### 영향점을 지우지 않는 이유
측정 비교에서는 크게 틀린 사람이 바로 **시계가 실패한 사례**일 수 있다. 근거(측정 실패 기록 등) 없이 지우면 정확도를 부풀린다. 주 분석은 전원 유지, 제외는 별도 시나리오로만 보인다.

## 출력
잔차 대 적합값, Q–Q, Cook's D 그림, 영향점 표, 한 명씩 제외 범위 표.

## 남은 질문
- 진단 결과 가정이 의심되면? → 다른 모형(로버스트 회귀 등)은 **다른 추정 대상**일 수 있어 우열 비교가 아니라 보완 질문으로 다룬다.
- 영향이 큰 사람의 원인(움직임, 착용 위치, 피부)은 평균 자료만으로 알 수 없다.
