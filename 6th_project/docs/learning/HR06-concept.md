# HR06 · CONCEPT — 같은 정의의 비교, 반올림, 수치 일치의 한계

> 일반 통계 개념 페이지. 숫자는 모두 **🧪 가상 예제**. 실제 적용은 [HR06-paper](HR06-paper.md).

## 입력
논문에 인쇄된 값(보통 반올림됨)과, 공개 자료로 다시 계산한 값.

## 이번 질문
"내가 계산한 값이 논문 값과 같은가?"보다 먼저 "**둘이 같은 것을 잰 값인가?**"를 묻는다.

## 방법과 이유

### 비교 가능성 점검표
1. 같은 자료 (같은 버전, 같은 표본, 같은 결측 처리)
2. 같은 추정 대상 (Pearson r ↔ Pearson r. Spearman ρ와 비교하지 않음)
3. 같은 단위와 집계 수준 (참가자 평균 ↔ 참가자 평균)
4. 같은 보고 척도 (고정 LoA ↔ 고정 LoA. 회귀식 LoA와 비교하지 않음)

하나라도 다르면 "불일치"가 아니라 "**비교 불가**"다.

### 허용오차는 결과를 보기 전에
소수 첫째 자리로 보고된 값 102.0은 실제로 101.95 ~ 102.05 사이 어딘가다. 그래서
- 소수 첫째 자리 값: |차이| ≤ 0.05
- 소수 둘째 자리 값: |차이| ≤ 0.005

결과를 본 뒤 허용오차를 넓히면, 무엇이든 "일치"로 만들 수 있다. **정한 시점을 기록**한다.

### 🧪 가상 예제: 반올림 순서가 결과를 바꾼다
시계 평균 93.44, 기준 평균 100.49.
- 차이를 먼저 계산 → −7.05 → 소수 첫째 자리 반올림: **−7.1**(0.5에서 0에서 멀어지게) 또는 **−7.0**(짝수 쪽으로, 부동소수 표현에 따라)
- 먼저 반올림 → 93.4 − 100.5 = **−7.1**

r = 0.9529를 0.95로 반올림한 뒤 CI를 계산하면 [0.881, 0.979] → "0.88 to 0.98", 반올림 전 값으로 계산하면 [0.888, 0.981] → "0.89 to 0.98". 하한이 0.01 달라진다.

### 일치가 말해 주는 것과 못 하는 것
| 관찰 | 말할 수 있음 | 말할 수 없음 |
|---|---|---|
| 반올림 범위 안에서 일치 | 같은 자료·정의로 그 숫자가 나올 수 있다 | 저자가 정확히 이 방법으로 계산했다 |
| 반올림된 중간값으로 계산하면 일치 | 그런 계산 경로와 호환된다 | 저자가 그렇게 했다 (다른 경로도 같은 값을 낼 수 있음) |
| 두 경로가 같은 값 | — | 어느 경로인지 (**식별 불가**) |
| 일치하지 않음 | 차이가 있다, 원인 조사 필요 | 논문이 틀렸다 (자료 버전·정의·내 오류 먼저 확인) |

### 사후 탐색의 표시
결과를 본 뒤 "이렇게 계산하면 맞을까?" 하고 후보를 만들면 그것은 **탐색적**(post-result)이다. 후보 수를 미리 정하고, 맞지 않은 후보도 모두 남긴다.

## 출력
항목별 원문 값 / 내 값 / 차이 / 사전 허용오차 / 판정(반올림 일치·불일치·비교 불가), 그리고 별도로 표시한 탐색적 후보 표.

## 남은 질문
- 원문이 계산 방법(CI 공식, 정규성 판정 기준)을 쓰지 않으면, 수치 일치만으로는 미확인으로 남는다.
- 수치가 다 맞아도 "그 분석이 질문에 적절한가"는 별개의 검토다 (HR07).
