# HR02 · CONCEPT — 산점도, Pearson 상관, 신뢰구간, 가정, Spearman

> 일반 통계 개념 페이지. 숫자는 모두 **🧪 가상 예제**. 실제 적용은 [HR02-paper](HR02-paper.md).

## 입력
같은 사람에게서 잰 (x, y) 짝 n개. 여기서는 x = 기준(ECG), y = 시계.

## 이번 질문
"기준값이 큰 사람일수록 시계값도 큰가? 그 **직선적 함께 움직임**이 얼마나 강한가?"
상관은 이 질문에만 답한다. "시계값이 기준값과 **같은가**"(일치)는 다른 질문이다 (HR04).

## 방법과 이유

### 산점도부터
숫자 하나로 줄이기 전에 점을 그린다. 곡선 관계, 한두 점의 쏠림, 두 무리 같은 구조는 r 하나로 보이지 않는다.

### Pearson r 최소 공식
```
r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[ Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)² ]
```
- −1 ~ +1. 부호는 방향, 크기는 직선에 얼마나 가까이 모였는지.
- 단위가 없다. y에 상수를 더하거나 양수를 곱해도 r은 그대로다 → **r은 치우침(bias)이나 기울기 차이를 볼 수 없다.**

### 🧪 가상 예제: 같은 사람 5명, 시계 3종
| 사람 | ECG x | 시계 A (=x−10) | 시계 B | 시계 C (=0.5x+50) |
|---|---|---|---|---|
| 1 | 60 | 50 | 62 | 80 |
| 2 | 80 | 70 | 78 | 90 |
| 3 | 100 | 90 | 101 | 100 |
| 4 | 120 | 110 | 119 | 110 |
| 5 | 140 | 130 | 140 | 120 |

시계 B의 r 계산: x̄ = 100, ȳ = 100.
- x 편차: −40, −20, 0, 20, 40 → Σ = 4000 (제곱합)
- y 편차: −38, −22, 1, 19, 40 → 제곱합 3890
- 곱의 합: 1520 + 440 + 0 + 380 + 1600 = 3940
- r = 3940 / √(4000 × 3890) = 3940 / 3944.6 ≈ **0.999**

시계 A와 C는 x의 정확한 직선 함수이므로 **r = 1**이다. 그런데 A는 모두 10 bpm 낮고, C는 60 bpm에서 +20, 140에서 −20 틀린다. **r = 1이어도 측정이 맞지 않을 수 있다.**

### 신뢰구간 (Fisher z)
r의 분포는 비대칭이라 z = atanh(r)로 바꿔 대칭에 가깝게 만든 뒤 구간을 잡고 되돌린다.
```
z = atanh(r),  SE = 1/√(n−3),  95% CI = tanh(z ± 1.96·SE)
```
🧪 r = 0.80, n = 22: z = 1.099, SE = 0.229 → tanh(0.650) ~ tanh(1.548) = **[0.57, 0.91]**. n이 작으면 구간이 넓다.

### 가정
- 관측끼리 독립 (같은 사람을 여러 번 세지 않음)
- 관계가 대략 직선
- CI·p값의 근사는 (x, y)가 대략 이변량 정규일 때 잘 맞는다. 이상치 한두 개가 r을 크게 흔들 수 있다.

### Spearman ρ가 답하는 질문
순위로 바꾼 뒤 Pearson r을 계산한 것. "**순서**가 같이 움직이는가(단조 관계)"를 묻는다. 이상치·비정규에 덜 민감하지만, **Pearson r과 다른 추정 대상**이므로 두 값을 서로 맞춰 보거나 바꿔 쓰지 않는다.

## 출력
- 산점도, r과 95% CI, (필요하면) ρ와 그 근사 CI.
- 해석 문장은 "함께 움직이는 정도"까지만. "정확하다"는 문장은 HR04의 오차 지표가 필요하다.

## 남은 질문
- 같은 r이라도 범위가 넓은 표본(쉬는 사람 + 뛰는 사람)에서는 r이 커지기 쉽다. 범위 효과를 어떻게 볼 것인가?
- 상관이 높을 때 시계가 **얼마나** 틀리는가? → HR03(기울기), HR04(오차).
