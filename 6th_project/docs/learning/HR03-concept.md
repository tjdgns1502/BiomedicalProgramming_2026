# HR03 · CONCEPT — 최소제곱 단순 선형회귀: 절편, 기울기, 잔차, R², 구간

> 일반 통계 개념 페이지. 숫자는 모두 **🧪 가상 예제**. 실제 적용은 [HR03-paper](HR03-paper.md).

## 입력
(x, y) 짝 n개. 여기서는 x = ECG, y = 시계. "시계 ~ ECG" 회귀는 "**ECG가 주어졌을 때 시계가 평균적으로 얼마를 내놓는가**"를 묻는다.

## 이번 질문
시계 값이 기준값을 따라갈 때 **기울기**(비례 관계)와 **절편**(고정된 차이)은 얼마인가? 완벽한 시계라면 y = x, 즉 절편 0, 기울기 1이다.

## 방법과 이유

### 최소 공식
```
ŷ = b₀ + b₁·x
b₁ = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)²      b₀ = ȳ − b₁·x̄
잔차 eᵢ = yᵢ − ŷᵢ,   s = √[ Σeᵢ² / (n − 2) ]
R² = 1 − Σeᵢ² / Σ(y − ȳ)²   (단순회귀에서는 R² = r²)
```
"최소제곱"은 잔차 제곱합을 가장 작게 만드는 직선을 고른다는 뜻이다.

### 🧪 가상 예제: HR02의 시계 B
x = 60, 80, 100, 120, 140 / y = 62, 78, 101, 119, 140
- b₁ = 3940 / 4000 = **0.985**, b₀ = 100 − 0.985 × 100 = **1.5**
- 적합값: 60.6, 80.3, 100.0, 119.7, 139.4
- 잔차: +1.4, −2.3, +1.0, −0.7, +0.6 (합 = 0)
- 잔차 제곱합 9.1 → s = √(9.1/3) = 1.74, R² = 1 − 9.1/3890 = **0.998**

### 잔차 ≠ 측정오차
- 측정오차 = 시계 − **기준값**: +2, −2, +1, −1, 0
- OLS 잔차 = 시계 − **회귀선 적합값**: +1.4, −2.3, +1.0, −0.7, +0.6

시계 C(= 0.5x + 50)는 OLS 잔차가 모두 0이고 R² = 1이다. 그런데 측정오차는 +20, +10, 0, −10, −20이다. **회귀선에 잘 맞는 것과 기준값에 맞는 것은 다르다.** 기울기 0.5가 "고강도에서 과소측정"을 알려 준다.

### 세 가지 구간을 섞지 않기
| 구간 | 질문 | 폭 |
|---|---|---|
| 계수 95% CI | 기울기·절편이 얼마쯤인가 | 좁음 |
| 평균반응 95% CI | x가 이 값인 사람들의 **평균** 시계값 | 중간 (그림의 띠) |
| 개인 예측 95% 구간 | x가 이 값인 **새 한 사람**의 시계값 | 넓음 |

### 가정
선형성, 잔차의 독립, 등분산, (작은 n에서 구간을 위해) 잔차 정규성. 점검은 HR05.

### 대안이 답하는 질문
- "시계 값으로 ECG를 예측하려면?" → ECG ~ 시계 회귀(방향이 다르면 기울기도 다르다).
- "두 방법 모두 오차가 있다면?" → Deming 회귀, Passing–Bablok 같은 방법 비교 회귀.
- "차이가 평균 크기에 따라 변하나?" → Bland–Altman 그림에서 차이 ~ 평균 회귀 (HR04).

## 출력
절편·기울기와 각 95% CI, R², 잔차 SE, 회귀선과 y = x를 함께 그린 그림.

## 남은 질문
- R²가 높다고 이 회귀식이 **다른 사람에게 보정식으로 쓸 만하다**고 할 수 있나? 아니다. 같은 자료에 맞춘 적합도일 뿐, 새 자료에서 검증하지 않았다.
- 기울기 CI에 1이 들어가면 "기울기가 1이다"인가? 아니다. "1과 다르다는 근거가 부족하다"일 뿐이며, n이 작으면 CI가 넓다.
