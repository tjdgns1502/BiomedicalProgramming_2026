# HR04 · CONCEPT — 측정오차: bias, MAE, RMSE, 분포, Bland–Altman

> 일반 통계 개념 페이지. 숫자는 모두 **🧪 가상 예제**. 실제 적용은 [HR04-paper](HR04-paper.md).

## 입력
짝 (시계, 기준) n개. 오차 eᵢ = 시계ᵢ − 기준ᵢ. **부호 규칙을 먼저 고정한다**: 음수 = 시계가 낮게 잼(과소측정).

## 이번 질문
"시계는 기준값과 **얼마나 같은가**?" 평균적으로 치우쳤는가(체계 오차), 사람마다 얼마나 흩어지는가(무작위 오차), 한 사람의 오차는 대략 어느 범위인가?

## 방법과 이유

### 최소 공식
```
bias = ē = Σeᵢ / n                     평균적 치우침
SD   = √[ Σ(eᵢ − ē)² / (n − 1) ]        사람 간 흩어짐
MAE  = Σ|eᵢ| / n                        부호를 뺀 평균 크기
RMSE = √( Σeᵢ² / n )  (≈ √(bias² + SD²))  치우침 + 흩어짐
bias의 95% CI = ē ± t(0.975, n−1) · SD/√n     "평균 오차"의 불확실성
고정 95% LoA  = ē ± 1.96 · SD                  "한 사람의 오차"가 놓일 범위
```

### 🧪 가상 예제: HR02의 시계 세 종류
| 시계 | 오차 e | bias | SD | MAE | RMSE | 95% LoA | r |
|---|---|---|---|---|---|---|---|
| A (x−10) | −10, −10, −10, −10, −10 | −10 | 0 | 10 | 10 | −10 ~ −10 | 1 |
| B | +2, −2, +1, −1, 0 | 0 | 1.58 | 1.2 | 1.41 | −3.1 ~ +3.1 | 0.999 |
| C (0.5x+50) | +20, +10, 0, −10, −20 | 0 | 15.8 | 12 | 14.1 | −31 ~ +31 | 1 |

- A: r = 1인데 모든 사람에게 10 bpm 낮다 → **체계 오차**.
- C: r = 1, bias = 0인데 개인 오차가 ±31 → bias만 보고 "정확"이라 할 수 없다.
- B만 상관·bias·흩어짐 모두 좋다.

### 두 구간을 섞지 않기
B에서 bias 95% CI = 0 ± 2.776 × 1.58/√5 = **−1.96 ~ +1.96**, LoA = **−3.1 ~ +3.1**.
CI는 n이 커지면 좁아진다(평균을 더 잘 앎). LoA는 n이 커져도 좁아지지 않는다(사람 간 흩어짐 자체).

### Bland–Altman 그림
x축 = (시계 + 기준)/2, y축 = 시계 − 기준. 수평선 3개: bias, bias ± 1.96 SD.
🧪 시계 C: 평균 70, 85, 100, 115, 130에서 차이 +20, +10, 0, −10, −20 → 오른쪽 아래로 기운 띠. **차이가 크기에 따라 변하면(비례 오차)** 고정 LoA 한 쌍은 맞지 않는다. 이때 "차이 ~ 평균" 회귀로 bias와 LoA를 평균의 함수로 쓰는 방법(가변 LoA)이 있다. 고정 LoA와 가변 LoA는 **추정 대상이 다르다**.

### 분포를 보는 이유
LoA의 ±1.96 SD는 오차가 대략 정규일 때 "95%"라는 뜻을 갖는다. 한쪽으로 긴 꼬리가 있으면 히스토그램·중앙값·최소/최대를 함께 본다.

### 가정과 대안 질문
- 사람끼리 독립, 오차의 평균·SD가 측정 범위 전체에서 비슷함.
- "얼마나 틀려도 괜찮은가?"는 통계가 정하지 않는다. 임상·사용 목적의 허용 범위를 **미리** 정해야 한다.
- "두 방법이 서로 바꿔 써도 되나?"는 LoA를 허용 범위와 비교하는 판단이다.

## 출력
기기별 bias(+95% CI), SD, MAE, RMSE, 고정 LoA, 오차 히스토그램, Bland–Altman 그림.

## 남은 질문
- 평균 HR 하나의 오차가 작아도, 운동 중 순간 HR의 오차는 클 수 있다(평균이 상쇄함).
- LoA 자체도 표본 추정치라 불확실성이 있다(LoA의 CI). 이번 범위에서는 계산하지 않았다.
