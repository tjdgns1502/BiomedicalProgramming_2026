## 2. 자료 정의와 분석 범위

공식 논문·공개 Key·수정 슬라이드에서 단위·짝·trial·열·집계 수준을 먼저 확인한다. 공개 HR는 22명×4기기의 참가자별 protocol 평균 88쌍이다. 기기별 n=22이며 88명의 독립 표본이 아니다. 해당 기기 착용 trial의 ECG와 짝짓고, 원래 행·셀·ID·헤더·소수 정밀도를 남긴다.

전체 88쌍을 주 분석에 사용하고 임의 축소·이상치 삭제·값 대체를 하지 않는다. 선정·결측·제외·변환이 생기면 이유·영향·입력/제외/사용 수를 기록하고 관련 하류 산출물을 갱신한다. 공개되지 않은 15초·활동별 HR를 생성하거나 다른 결과변수로 대체하지 않는다.

필수는 산점도, Pearson 상관·불확실성, 시계~ECG 단순 선형회귀, 측정오차와 지정 그림이다. 명시된 잔차·Q–Q·Cook·한 명씩 제외하는 보조 민감도만 연결한다. EE·ICC·하위집단 등 범위 밖 결과를 자동으로 확대하지 않는다.

각 단계는 concept/paper MD 두 개를 짝지어 `입력 → 질문 → 방법과 이유 → 출력 → 남은 질문`으로 작성한다. concept에는 용어·최소 공식·작은 가상 계산·가정·대안의 질문을, paper에는 원변수·정의·변환·선정·구현·실제 표/그림·해석·출처를 둔다. 가상 원리 예제와 실제 ID/셀 예제를 명확히 표시한다.

단계 등록부 `analysis/stage_registry.json`에 ID·관측 단위·입출력·읽기 순서·실행 의존성·concept/paper 경로·원문 근거·그림·문제 ID를 유지한다. 학습 순서를 저자 실행 순서로 주장하지 않는다.

## 4. 최종 HTML 한 파일의 출력 계약

최종 HTML 본문에서도 HR01–HR07마다 **CONCEPT / 일반 통계 개념 → PAPER / 논문·실제 데이터 적용**을 별도 제목과 패널로 보여 준다. MD를 합쳐 결과 서술 하나로 대체하지 않는다. 두 설명은 기본 상태에서 읽을 수 있게 한다.

결과 요약, 자료 흐름, 7개 학습 쌍, 실제 표·그림, 전체 88쌍, 문제·수정·실패·한계, MD 원문/저장을 포함한다. 현재 본문에 사용하는 분석 그림 7개를 내장하고 원본 PNG·STYLE1·표·모형은 별도 파일로 보존한다. 필터는 표시만 바꾸고 분석 분모를 바꾸지 않으며 CSV 다운로드는 전체 88쌍을 제공한다.

HTML의 스타일·그림·필요한 동작을 내장해 별도 그림 폴더나 외부 CDN 없이 열리게 한다. 원문과 로컬 근거 링크를 제공하되 핵심 설명은 HTML 안에서 완결한다. 완성 보고서 HTML은 한 개로 유지한다. 이전 HTML은 이력 폴더에서 최종 전달물과 구별해 보존한다.

PC·모바일에서 넘침·목차·그림·표·concept/paper 구분·로컬 링크를 확인한다. 제공한 문제 펼침, 기기별 표시, 전체 CSV, MD 저장, 가상 예제와 인쇄가 실제 작동하는지 확인한다. 문서의 단위·분모·CI 종류·자료/실행 버전을 대조한다.

## 5. 구현·해석·기록

통계·계획의 정본은 config와 run이며 MD·HTML 수치는 검토된 CSV에서 연결한다. R readxl/cor/lm을 사용하고 Python 보조 작업은 uv로 실행한다. 새 통계 실행은 새 run ID를 쓰며 원자료·기존 run·실패를 덮어쓰지 않는다.

상관은 일치·정확도와 구별하고, 잔차는 시계−ECG 측정오차와 구별한다. 평균반응 CI·개인 예측구간·평균오차 CI·LoA를 혼합하지 않는다. 한 명씩 제외하는 범위는 CI나 외부 예측 교차검증 결과가 아니다. OLS의 적합 R²를 검증된 보정 성능으로 표현하지 않는다.

원문의 Samsung 0.67은 Spearman이며 과제 Pearson 약 0.743을 바꾸지 않는다. 원문 Mio 가변 LoA와 과제 고정 LoA를 같은 결과로 비교하지 않는다. 반올림 호환 점검은 저자 구현을 입증한 사실과 구별하고 허용오차를 정한 시점을 기록한다.

확인 사실·분석자 선택·원문 미보고·모순을 구분한다. R 수식 확인과 동일 에이전트의 Python 대조를 외부·맹검·독립 심사로 부르지 않는다. 임상적 교환 가능성, 현재 시계 성능, 활동별 순간 정확도나 인과효과를 이 평균자료로 확정하지 않는다.

자료/통계 코드가 바뀌면 관련 결과·그림·문서를, 해석이 바뀌면 근거·문구를, 서식만 바뀌면 화면·해당 기능을 확인한다. 문서 구조 수정 때문에 고정된 통계를 재적합하지 않는다. 검토한 파일 버전·해시와 범위를 남긴다.
