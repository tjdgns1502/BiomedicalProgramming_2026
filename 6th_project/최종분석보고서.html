현재 재현 수준

  • 원문 Table 1 HR 블록: 사전 규칙으로 부분 일치(39개 일치, 7개 불일치, 7개 비교 불가). 불일치는 모두 반올림된 중간값으로 계산한 경로와 호환된다(탐색적, 저자 구현 미확인).
  • 과제 범위(산점도, Pearson, OLS, 측정오차, 지정 그림): 모두 구현했고, 별도 문맥 코드 감사에서 결과를 바꾸는 오류가 없었다.

중요한 발견

  1. Samsung의 원문 0.67은 Spearman ρ이고, 과제의 Pearson r은 0.743이다. 서로 다른 통계량이다.
  2. Fitbit은 r = 0.81인데 22명 중 21명을 낮게 읽었고, 기울기 0.64(CI가 1을 포함하지 않음)로 HR이 높을수록 더 낮게 읽는 모양이다.
  3. 원문 HR 표의 파생값(CI 경계, LoA)은 반올림된 r·bias·SD로 계산한 값과 호환된다.

HR02 · 산점도와 Pearson 상관
질문: ECG가 높은 사람일수록 시계도 높게 읽는가, 그 직선 관계는 얼마나 강한가?


CONCEPT / 일반 통계 개념
HR02 · CONCEPT — 산점도, Pearson 상관, 신뢰구간, 가정, Spearman




일반 통계 개념 페이지. 숫자는 모두 🧪 가상 예제. 실제 적용은 HR02-paper.




입력


같은 사람에게서 잰 (x, y) 짝 n개. 여기서는 x = 기준(ECG), y = 시계.


이번 질문


"기준값이 큰 사람일수록 시계값도 큰가? 그 직선적 함께 움직임이 얼마나 강한가?"
상관은 이 질문에만 답한다. "시계값이 기준값과 같은가"(일치)는 다른 질문이다 (HR04).


방법과 이유


산점도부터


숫자 하나로 줄이기 전에 점을 그린다. 곡선 관계, 한두 점의 쏠림, 두 무리 같은 구조는 r 하나로 보이지 않는다.


Pearson r 최소 공식


r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √[ Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)² ]



    

  • −1 ~ +1. 부호는 방향, 크기는 직선에 얼마나 가까이 모였는지.
    • 

  • 단위가 없다. y에 상수를 더하거나 양수를 곱해도 r은 그대로다 → r은 치우침(bias)이나 기울기 차이를 볼 수 없다.
    •

신뢰구간 (Fisher z)


r의 분포는 비대칭이라 z = atanh(r)로 바꿔 대칭에 가깝게 만든 뒤 구간을 잡고 되돌린다.


z = atanh(r),  SE = 1/√(n−3),  95% CI = tanh(z ± 1.96·SE)

    •

순위로 바꾼 뒤 Pearson r을 계산한 것. "순서가 같이 움직이는가(단조 관계)"를 묻는다. 이상치·비정규에 덜 민감하지만, Pearson r과 다른 추정 대상이므로 두 값을 서로 맞춰 보거나 바꿔 쓰지 않는다.

HR03 · 시계 ~ ECG 단순 선형회귀
질문: ECG가 1 bpm 오를 때 시계는 평균 몇 bpm 오르는가? y = x에서 어디서 벗어나는가?


CONCEPT / 일반 통계 개념
HR03 · CONCEPT — 최소제곱 단순 선형회귀: 절편, 기울기, 잔차, R², 구간




일반 통계 개념 페이지. 숫자는 모두 🧪 가상 예제. 실제 적용은 HR03-paper.




입력


(x, y) 짝 n개. 여기서는 x = ECG, y = 시계. "시계 ~ ECG" 회귀는 "ECG가 주어졌을 때 시계가 평균적으로 얼마를 내놓는가"를 묻는다.


이번 질문


시계 값이 기준값을 따라갈 때 기울기(비례 관계)와 절편(고정된 차이)은 얼마인가? 완벽한 시계라면 y = x, 즉 절편 0, 기울기 1이다.


방법과 이유


최소 공식


ŷ = b₀ + b₁·x
b₁ = Σ(x − x̄)(y − ȳ) / Σ(x − x̄)²      b₀ = ȳ − b₁·x̄
잔차 eᵢ = yᵢ − ŷᵢ,   s = √[ Σeᵢ² / (n − 2) ]
R² = 1 − Σeᵢ² / Σ(y − ȳ)²   (단순회귀에서는 R² = r²)



"최소제곱"은 잔차 제곱합을 가장 작게 만드는 직선을 고른다는 뜻이다.


🧪 가상 예제: HR02의 시계 B


x = 60, 80, 100, 120, 140 / y = 62, 78, 101, 119, 140


    

  • b₁ = 3940 / 4000 = 0.985, b₀ = 100 − 0.985 × 100 = 1.5
    • 

  • 적합값: 60.6, 80.3, 100.0, 119.7, 139.4
    • 

  • 잔차: +1.4, −2.3, +1.0, −0.7, +0.6 (합 = 0)
    • 

  • 잔차 제곱합 9.1 → s = √(9.1/3) = 1.74, R² = 1 − 9.1/3890 = 0.998
    • 



잔차 ≠ 측정오차


    

  • 측정오차 = 시계 − 기준값: +2, −2, +1, −1, 0
    • 

  • OLS 잔차 = 시계 − 회귀선 적합값: +1.4, −2.3, +1.0, −0.7, +0.6
    • 



시계 C(= 0.5x + 50)는 OLS 잔차가 모두 0이고 R² = 1이다. 그런데 측정오차는 +20, +10, 0, −10, −20이다. 회귀선에 잘 맞는 것과 기준값에 맞는 것은 다르다. 기울기 0.5가 "고강도에서 과소측정"을 알려 준다.

질문: 시계는 ECG와 평균적으로, 그리고 사람마다 얼마나 다른가? 상관이 높아도 어긋날 수 있는가?


CONCEPT / 일반 통계 개념
HR04 · CONCEPT — 측정오차: bias, MAE, RMSE, 분포, Bland–Altman




일반 통계 개념 페이지. 숫자는 모두 🧪 가상 예제. 실제 적용은 HR04-paper.




입력


짝 (시계, 기준) n개. 오차 eᵢ = 시계ᵢ − 기준ᵢ. 부호 규칙을 먼저 고정한다: 음수 = 시계가 낮게 잼(과소측정).


이번 질문


"시계는 기준값과 얼마나 같은가?" 평균적으로 치우쳤는가(체계 오차), 사람마다 얼마나 흩어지는가(무작위 오차), 한 사람의 오차는 대략 어느 범위인가?


방법과 이유


최소 공식


bias = ē = Σeᵢ / n                     평균적 치우침
SD   = √[ Σ(eᵢ − ē)² / (n − 1) ]        사람 간 흩어짐
MAE  = Σ|eᵢ| / n                        부호를 뺀 평균 크기
RMSE = √( Σeᵢ² / n )  (≈ √(bias² + SD²))  치우침 + 흩어짐
bias의 95% CI = ē ± t(0.975, n−1) · SD/√n     "평균 오차"의 불확실성
고정 95% LoA  = ē ± 1.96 · SD                  "한 사람의 오차"가 놓일 범위

분포를 보는 이유


LoA의 ±1.96 SD는 오차가 대략 정규일 때 "95%"라는 뜻을 갖는다. 한쪽으로 긴 꼬리가 있으면 히스토그램·중앙값·최소/최대를 함께 본다.

HR05 · 잔차 진단과 한 명씩 제외
질문: 회귀 가정이 크게 어긋나는가? 한 사람이 결론을 좌우하는가?


CONCEPT / 일반 통계 개념
HR05 · CONCEPT — 잔차 진단, Q–Q, 영향점, 민감도의 의미




일반 통계 개념 페이지. 숫자는 모두 🧪 가상 예제. 실제 적용은 HR05-paper.




입력


HR03에서 적합한 OLS 모형과 잔차, HR04의 오차 요약.


이번 질문


"결과가 회귀 가정을 크게 어기지 않는가? 한두 사람이 결론을 좌우하는가?" 진단은 결과를 고르려는 것이 아니라 결과를 얼마나 믿을지 알려는 것이다.


방법과 이유


잔차 대 적합값 그림


가로 = 적합값, 세로 = 잔차. 0 주위에 고르게 퍼지면 좋다.


    

  • 곡선 모양 → 직선 관계가 아님
    • 

  • 깔때기 모양 → 등분산 위반
    • 

  • 홀로 멀리 떨어진 점 → 이상치 후보
    • 



표준화 잔차와 Q–Q 그림


표준화 잔차 = 잔차 / (s·√(1 − hᵢ)). 대략 정규라면 |값| > 2는 20명 중 1명 정도로 드물다.
Q–Q 그림: 표준화 잔차를 크기순으로 놓고 정규분포 분위수와 짝지어 그린다. 직선 위에 있으면 정규에 가깝다. n = 22 정도에서는 우연히도 꼬리가 휘기 쉬워 강한 결론을 내리지 않는다.


레버리지와 Cook's distance


레버리지 hᵢ = 1/n + (xᵢ − x̄)² / Σ(x − x̄)²       x가 평균에서 멀수록 큼
Cook's Dᵢ = (eᵢ² / (p·s²)) · hᵢ / (1 − hᵢ)²      p = 계수 수(2)



Cook's D는 "i를 빼면 적합선이 얼마나 움직이나"를 한 숫자로 요약한다. 4/n 같은 기준선은 경험칙이지 검정이 아니다.


    

  • 잔차가 커도 x가 가운데면(레버리지 작음) 선을 많이 못 움직인다.
    • 

  • 잔차가 작아도 x가 끝에 있으면(레버리지 큼) 선을 끌어당길 수 있다.
    • 



한 명씩 제외(leave-one-out) 민감도


n번 다시 계산하며 매번 한 명을 뺀다.
🧪 시계 B 오차 +2, −2, +1, −1, 0에서 한 명씩 빼면 bias = −0.5, +0.5, −0.25, +0.25, 0 → 범위 −0.5 ~ +0.5.


    

  • 이 범위는 신뢰구간이 아니다(표본추출 확률 해석이 없음).
    • 

  • 교차검증도 아니다(새 사람에 대한 예측 성능을 재지 않음).
    • 

  • "특정 한 사람이 결론을 뒤집는가"만 보여 준다.
    • 



영향점을 지우지 않는 이유


측정 비교에서는 크게 틀린 사람이 바로 시계가 실패한 사례일 수 있다. 근거(측정 실패 기록 등) 없이 지우면 정확도를 부풀린다. 주 분석은 전원 유지, 제외는 별도 시나리오로만 보인다.


출력


잔차 대 적합값, Q–Q, Cook's D 그림, 영향점 표, 한 명씩 제외 범위 표.


남은 질문


    

  • 진단 결과 가정이 의심되면? → 다른 모형(로버스트 회귀 등)은 다른 추정 대상일 수 있어 우열 비교가 아니라 보완 질문으로 다룬다.
    • 

  • 영향이 큰 사람의 원인(움직임, 착용 위치, 피부)은 평균 자료만으로 알 수 없다.
    •

CONCEPT / 일반 통계 개념
HR06 · CONCEPT — 같은 정의의 비교, 반올림, 수치 일치의 한계




일반 통계 개념 페이지. 숫자는 모두 🧪 가상 예제. 실제 적용은 HR06-paper.




입력


논문에 인쇄된 값(보통 반올림됨)과, 공개 자료로 다시 계산한 값.


이번 질문


"내가 계산한 값이 논문 값과 같은가?"보다 먼저 "둘이 같은 것을 잰 값인가?"를 묻는다.


방법과 이유


비교 가능성 점검표


    

  1. 같은 자료 (같은 버전, 같은 표본, 같은 결측 처리)
    2. 

  2. 같은 추정 대상 (Pearson r ↔ Pearson r. Spearman ρ와 비교하지 않음)
    3. 

  3. 같은 단위와 집계 수준 (참가자 평균 ↔ 참가자 평균)
    4. 

  4. 같은 보고 척도 (고정 LoA ↔ 고정 LoA. 회귀식 LoA와 비교하지 않음)
    5. 



하나라도 다르면 "불일치"가 아니라 "비교 불가"다.


허용오차는 결과를 보기 전에


소수 첫째 자리로 보고된 값 102.0은 실제로 101.95 ~ 102.05 사이 어딘가다. 그래서


    

  • 소수 첫째 자리 값: |차이| ≤ 0.05
    • 

  • 소수 둘째 자리 값: |차이| ≤ 0.005
    • 



결과를 본 뒤 허용오차를 넓히면, 무엇이든 "일치"로 만들 수 있다. 정한 시점을 기록한다.


🧪 가상 예제: 반올림 순서가 결과를 바꾼다


시계 평균 93.44, 기준 평균 100.49.

    • 

  • 먼저 반올림 → 93.4 − 100.5 = −7.1
    • 



r = 0.9529를 0.95로 반올림한 뒤 CI를 계산하면 [0.881, 0.979] → "0.88 to 0.98", 반올림 전 값으로 계산하면 [0.888, 0.981] → "0.89 to 0.98". 하한이 0.01 달라진다.
