4. 🧪 가상 예제 계산기

가상 예제 — 실제 자료가 아니다. 5명의 가상 ECG와 시계 값을 바꿔 보며 r, 회귀선, 오차가 각각 무엇에 반응하는지 확인한다. 미리 넣은 A·B·C는 CONCEPT 페이지(HR02–HR04)의 예와 같다.

사람ECG x시계 y오차 y−x

r과 R²는 y에 상수를 더하거나 곱해도 변하지 않는다(A, C에서 r = 1). bias·SD·LoA는 y = x에서 얼마나 떨어졌는지를 직접 잰다. 점선 = y = x, 실선 = OLS.
