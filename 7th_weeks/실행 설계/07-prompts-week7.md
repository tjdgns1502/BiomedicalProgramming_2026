# 7주차 실행 지시와 일관성 보강

원본 v2.0을 7주차 입력에 맞춘 파일: [[07-prompts-v2.0-week7]]. 5주차 원본을 바꾸지 않고 이번 입력을 아래처럼 고정했습니다.

작업 루트: 현재 7주차 폴더. 학습 문서 원본: `근감소증과 인체계측 - 분석 길잡이`. 논문: Wu et al. 2024, DOI 10.1038/s41598-024-82751-7, PMID 39738342. `논문.pdf`가 추가되었으므로 원문 PDF를 확인한다. 과제: NHANES 2011–2018의 가중 로지스틱 회귀와 진단 성능, Table 3·4 및 ROC 재현, 학습·검증 8:2 분할. 언어 Python, 환경과 실행은 uv. 논문과 다른 과제 확장은 assignment_extension.

## 이전 분석 일관성 문제를 막는 실행 규칙

1. 원자료 SHA256→파생자료 data_version→selection/domain→model/formula/weight→table/figure→학습노트의 의존성을 등록한다.
2. 근감소증 판정·인체계측 지표·공변량·결측·가중치·분모를 바꾸면 영향을 받은 모든 후속 task와 문서를 stale 표시한다. accepted라도 stale은 재사용하지 않는다.
3. 새 run_id에서 계산하고 독립검토를 다시 받는다. 이전 결과를 덮어쓰거나 한 표 안에 다른 버전 수치를 혼합하지 않는다.
4. 모든 그림은 run과 분석집단·모형·CI 규칙을 표시한다. 읽기용 assets 사본도 hash를 남긴다.
5. 원문 수치 목표는 구현자에게 전달하지 않는다. 수치 비교는 실행 후 조정자가 한다. 후보의 숫자 일치와 통계적 타당성 판정을 분리한다.
6. 독립 검토는 정확한 코드/결과 hash를 기록한다. 에이전트 검토를 새 외부 표본 검증으로 표현하지 않는다.

검토된 7주차 계획: 아직 미확인. 기존 예비 분석의 계획과 결과를 조사하고 필요한 계획을 작성·검토한다. 모든 본문·보충 산출물과 과제요구는 output_coverage에 추적한다. 재현 가능한 필수 작업을 실행하지 않고 종료하지 않는다. 식별할 수 없는 저자 설정은 후보와 한계를 표시한다.
