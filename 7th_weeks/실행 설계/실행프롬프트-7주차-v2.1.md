공통 기준: `전체실행프롬프트-v2.1-7주차.md`. 6주차 v2.1의 분석·검토·단일 HTML 출력 계약을 유지하고 7주차 논문과 자료를 적용한다. 사용자 최신 지시가 우선한다.

## 입력과 분석 범위

작업 루트: 이 파일의 상위 7주차 폴더. 논문: `논문.pdf`, Wu 등 2024, DOI 10.1038/s41598-024-82751-7, PMID 39738342. 자료: NHANES 2011–2018 공식 공개 데이터와 코드북. Python은 uv로 실행한다. 기존 자료·코드·실행 기록을 확인하고 재사용 가능 여부를 따진다.

논문의 선정, 근감소증·근감소성 비만 정의, 지표·공변량·가중치와 Table 3의 OR·95% CI·p값, Table 4의 AUC·Youden 지수·민감도·특이도, Figure 2 ROC를 검토한다. 학습·검증 8:2 분할에서 학습 자료의 컷오프를 고정하여 검증한다. 원문의 모델 설정과 지표 증가 단위가 미보고된 경우 후보로 표시한다. Table 4에 컷오프 값이 보고되지 않았음을 밝힌다. BMI가 결과 정의에 들어가는 구조, 복합표본 분산과 예측정보 누출을 점검한다.

## 학습 문서 및 최종 전달물

학습 문서 정본은 `근감소증과 인체계측 - 분석 길잡이/`, 최종 전달물은 `최종분석보고서.html` 한 파일이다. MD는 편집·근거 자료로 보존하고 HTML은 최종 전달물로 사용한다. 연구와 변수, 회귀와 복합표본, ROC·검증 등 각 단계에서 일반 통계 CONCEPT와 논문·실제 분석 PAPER를 별도 패널로 기본 표시한다.

HTML에는 질문·방법·대상자 흐름·원문 수치와 후보 결과·ROC 그림·모형과 단위·분모·자료 출처·문제와 한계를 포함한다. 필요한 그림·표·스타일·동작을 HTML 안에 내장하고 외부 CDN 없이 열리게 한다. 분석 자료를 공개할 수 있는 범위에서 확인·다운로드하게 하되 필터는 표시만 바꾼다. 원문과 후보의 값, 검증 완료와 미완료를 명확하게 구분한다.

코드·자료·run을 변경하지 않는 문서 수정은 통계 재분석 없이 근거 CSV와 해시를 확인한다. PC·모바일의 목차·패널·그림·표·기능과 문서의 단위·표본수·한계를 점검한다. 완료 시 최신 프롬프트, 최종 HTML과 학습 정본, 재현 범위와 제한을 안내한다.

## 기존 결과의 지위

`analysis/runs/candidate_20261108_v2/`는 8,086명의 후보 분석이다. 질환 자가보고 대체 변수, 저자의 미보고 설정, 지표 직접 ROC와 단계적 예측모형의 차이 때문에 정확 재현으로 단정하지 않는다. 실패한 이전 실행은 보존한다. HTML 작성이 과거 분석의 사전 계획이나 검토 상태를 소급 변경하지 않는다.
