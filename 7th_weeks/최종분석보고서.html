CONCEPT · 일반 개념

연구 질문과 한 사람의 자료

NHANES는 여러 단계로 사람을 추출한 횡단면 조사다. 한 행은 한 참가자이며 SEQN으로 인구학, 검사, 식이, 설문을 연결한다. 결과는 같은 시점의 낮은 근육량 분류와 지표 사이의 연관 및 구분 능력이다. 미래에 생길 질병이나 원인 효과를 직접 보여주지 않는다.

예를 들어 한 사람의 허리둘레가 90 cm, 키가 170 cm면 WHtR=0.90/1.70≈0.529다. 이 값은 개인의 입력이다. 회귀 OR과 ROC는 전체 사람들의 자료로 계산하며 이 예시 한 사람의 효과가 아니다.

BMI가 질환 기준과 지표에 동시에 들어가면 변수들이 정의상 정보를 공유한다. 이때 높은 판별력이 지표의 독립적인 임상적 유용성만을 의미하지 않는다.

가중 로지스틱 회귀 읽기

로짓은 log(p/(1−p))이고 지표 계수 β를 지수화한 exp(β)가 해당 지표의 정해진 증가 단위에 대한 오즈비(OR)다. OR 1.5는 다른 변수 고정 시 오즈가 1.5배라는 뜻이며, 위험확률이 반드시 1.5배라는 뜻은 아니다. 95% CI는 추정의 불확실성을 보여준다. p값은 귀무가설과 자료의 불일치 정도이며 효과의 크기나 인과성 자체가 아니다.

가중치는 표본의 대표성을 조정하고, 층·PSU는 불확실성을 계산할 때 조사 설계에 반영한다. 단순 가중 GLM의 기본 표준오차는 층화·군집을 반영한 표준오차와 같다고 가정할 수 없다. 선택된 사람만 남긴 뒤 설계 밖 PSU를 없애지 않도록 도메인 분석에 주의한다.

논문 모델 1은 단변량, 2는 인구학 변수, 3은 건강·활동·식이를 추가한다. 이번 분석은 세 모델 모두 동일한 8,086명 완전사례에 2일 식이가중치 WTDR2D/4를 사용했다. 가중 우도에 층별 PSU 점수의 Taylor 선형화 분산과 t 자유도를 적용했다. 저자의 실제 가중치와 공변량 세부 정의는 확인되지 않았다.

예: SA의 BRI 1 증가당 모델 3 OR은 1.709 (95% CI 1.614–1.809, p<0.001), 논문은 1.67 (1.59–1.76)이다. 수치가 비슷해도 표본과 정의가 달라 정확 재현은 아니다. ABSI는 0.01 증가, WHtR는 0.1 증가를 분석자가 지정했으며 논문 표의 증가 단위는 확인되지 않았다. LBSIZ도 표준화 기준이 다를 수 있어 단위 일치 없이 비교하지 않는다.

CONCEPT · 일반 개념

ROC와 Youden 지수

민감도는 실제 양성 중 양성으로 분류한 비율, 특이도는 실제 음성 중 음성으로 분류한 비율이다. ROC는 여러 컷오프의 민감도와 1−특이도를 연결하며 AUC는 양성과 음성의 점수를 얼마나 잘 구분하는지 요약한다. Youden 지수 J=민감도+특이도−1이다.

학습 자료에서 J를 최대화하는 컷오프를 선택한 뒤 검증 자료에는 그 값을 고정한다. 검증 자료에서 다시 최적화하면 성능이 낙관적일 수 있다. 같은 조사 자료를 무작위로 나눈 검증은 내부 검증이며 외부 표본의 독립 검증이 아니다. 가중 ROC의 불확실성은 복합표본 설계를 반영해 별도로 추정해야 한다.

완전사례를 결과별 층화하여 8:2로 나누고 seed 42, WTDR2D 가중치를 사용했다. 학습 6,468명에서 Youden 최대 컷오프를 고르고 검증 1,618명에서 고정 컷오프를 평가했다. 저자 시드·분할·예측모형은 미확인이다. 직접 지표 ROC이므로 단계적 회귀 후 예측모형을 언급한 논문 Table 4의 정확한 재현이 아니다.

SA의 BRI 학습 AUC는 0.846, 검증 AUC는 0.823이며 학습 컷오프 5.994에서 검증 민감도 0.753, 특이도 0.752다. 논문의 SA BRI 학습 AUC는 0.867이다. 컷오프는 원문 Table 4에 없으므로 이 값은 분석자 추정치다. BRI와 WHtR는 단조 변환 관계여서 같은 사람과 가중치에서 직접 지표 ROC가 동일하다. 원문의 두 AUC는 서로 달라 모형 등 미보고 설정을 확인해야 한다.

7주차 논문 근거 정리

출처: 논문.pdf, Wu X, Chen Z, Zhao Y, Ren H. Scientific Reports 14:31776 (2024), doi:10.1038/s41598-024-82751-7. 아래 쪽수는 PDF의 실제 쪽수다. 원문 보고와 재현 후보를 구별했다.

연구 설계·선정 (2–3쪽, Figure 1)

횡단면 연구이며 2011–2018년 DXA를 주 분석, 2001–2004년 BIA를 별도 검증에 사용했다고 보고한다. 표본 흐름은 39,156명 → 20세 미만 16,539명과 DXA 결측 10,486명 제외 → 12,131명 → 체형(body type) 결측 1,971명, 에너지 섭취 및 신체활동 결측 2,001명 제외 → 최종 8,159명. 각 단계의 변수 목록과 결측 적용 순서의 세부 코드 및 기타 공변량 결측 규칙은 명시되지 않았다.

대상 질환 및 지표 (3–4쪽)

논문은 DXA의 total skeletal muscle mass/BMI가 남성 0.789 미만, 여성 0.512 미만이면 SA로 정의하고, SA이면서 BMI ≥30이면 SO로 정의했다. 실제로 DXA의 어떤 열을 어떻게 더했는지 이 본문 표현만으로 확정하지 못한다. FNIH 기준을 근거로 사지 제지방량 합을 쓰는 것은 검증할 후보이며 저자 코드라고 단정하지 않는다. 근력·신체 기능을 포함하지 않은 이 조작적 정의와 임상 진단 전체는 구별한다.

WHtR=허리둘레(m)/키(m), BMI=체중(kg)/키(m)², ABSI=허리둘레(m)/(BMI^(2/3)×키(m)^(1/2)), BRI=364.2−365.5√[1−{허리둘레(m)/(2π)}²/{0.5×키(m)}²], LBSIZ=[log(ABSI)−평균 log(ABSI)]/표준편차 log(ABSI). LBSIZ의 평균·표준편차를 어떤 모집단과 가중 방식으로 계산했는지는 더 확인해야 한다. 예측 분석에서는 학습 자료의 값을 고정해 검증 자료에 적용한다.

식이는 2일 일평균 에너지·단백질, 좌식 시간은 <4, 4–6, 6–8, >8시간의 4범주로 설명한다(3쪽). 정확한 경계값·불응·결측 코딩은 확인이 필요하다. BMI가 SA 판정과 SO 판정에 직접 들어가므로 BMI 관련 지표의 분류 성능에는 결과 정의와의 수학적 공유가 있다.

통계 및 모델 (4·6쪽)

R 4.3.3과 survey 패키지로 전 분석에 가중치를 적용했다고 기술한다(4쪽). Table 3 모델 1은 단변량, 모델 2는 연령·성별·인종·빈곤·교육, 모델 3은 모델 2 변수에 고혈당·고혈압·고콜레스테롤·신체활동 부족·좌식 시간·열량 및 단백질 섭취를 추가한다(6쪽). 세부 범주화, 참조군, 정확한 지표 증가 단위, 선택된 가중치·층·PSU·분산 추정 및 각 모델의 분모는 원문에서 충분히 식별되지 않는다. 표의 별표는 p<0.05이며 정확한 p값은 표시되지 않는다.

해석 범위

횡단면 연관과 동시점 구분 성능은 미래 발병 예측이나 인과효과를 증명하지 않는다. 본문의 6쪽 RCS 결과 문단에 이 논문 결과와 다른 수면무호흡·코골이 문구가 있어 해당 부분은 문맥상 불일치로 기록한다. 논문에서 2011–2018 전체에 대해 20세 이상이라 적더라도 DXA 참여 가능 연령의 공식 코드북 범위와 결측에 따른 적용 대상을 확인해야 한다.

# 연구 질문과 한 사람의 자료

NHANES는 여러 단계로 사람을 추출한 횡단면 조사다. 한 행은 한 참가자이며 SEQN으로 인구학, 검사, 식이, 설문을 연결한다. 결과는 같은 시점의 낮은 근육량 분류와 지표 사이의 연관 및 구분 능력이다. 미래에 생길 질병이나 원인 효과를 직접 보여주지 않는다.

예를 들어 한 사람의 허리둘레가 90 cm, 키가 170 cm면 WHtR=0.90/1.70≈0.529다. 이 값은 개인의 입력이다. 회귀 OR과 ROC는 전체 사람들의 자료로 계산하며 이 예시 한 사람의 효과가 아니다.

BMI가 질환 기준과 지표에 동시에 들어가면 변수들이 정의상 정보를 공유한다. 이때 높은 판별력이 지표의 독립적인 임상적 유용성만을 의미하지 않는다.

# 가중 로지스틱 회귀 읽기

로짓은 log(p/(1−p))이고 지표 계수 β를 지수화한 exp(β)가 해당 지표의 정해진 증가 단위에 대한 오즈비(OR)다. OR 1.5는 다른 변수 고정 시 오즈가 1.5배라는 뜻이며, 위험확률이 반드시 1.5배라는 뜻은 아니다. 95% CI는 추정의 불확실성을 보여준다. p값은 귀무가설과 자료의 불일치 정도이며 효과의 크기나 인과성 자체가 아니다.

가중치는 표본의 대표성을 조정하고, 층·PSU는 불확실성을 계산할 때 조사 설계에 반영한다. 단순 가중 GLM의 기본 표준오차는 층화·군집을 반영한 표준오차와 같다고 가정할 수 없다. 선택된 사람만 남긴 뒤 설계 밖 PSU를 없애지 않도록 도메인 분석에 주의한다.

논문 모델 1은 단변량, 2는 인구학 변수, 3은 건강·활동·식이를 추가한다. 이번 분석은 세 모델 모두 동일한 8,086명 완전사례에 2일 식이가중치 WTDR2D/4를 사용했다. 가중 우도에 층별 PSU 점수의 Taylor 선형화 분산과 t 자유도를 적용했다. 저자의 실제 가중치와 공변량 세부 정의는 확인되지 않았다.

# ROC와 Youden 지수

민감도는 실제 양성 중 양성으로 분류한 비율, 특이도는 실제 음성 중 음성으로 분류한 비율이다. ROC는 여러 컷오프의 민감도와 1−특이도를 연결하며 AUC는 양성과 음성의 점수를 얼마나 잘 구분하는지 요약한다. Youden 지수 J=민감도+특이도−1이다.

학습 자료에서 J를 최대화하는 컷오프를 선택한 뒤 검증 자료에는 그 값을 고정한다. 검증 자료에서 다시 최적화하면 성능이 낙관적일 수 있다. 같은 조사 자료를 무작위로 나눈 검증은 내부 검증이며 외부 표본의 독립 검증이 아니다. 가중 ROC의 불확실성은 복합표본 설계를 반영해 별도로 추정해야 한다.

# Table 4와 ROC: 후보 직접 지표 분석

완전사례를 결과별 층화하여 8:2로 나누고 seed 42, WTDR2D 가중치를 사용했다. 학습 6,468명에서 Youden 최대 컷오프를 고르고 검증 1,618명에서 고정 컷오프를 평가했다. 저자 시드·분할·예측모형은 미확인이다. 직접 지표 ROC이므로 단계적 회귀 후 예측모형을 언급한 논문 Table 4의 정확한 재현이 아니다.

SA의 BRI 학습 AUC는 0.846, 검증 AUC는 0.823이며 학습 컷오프 5.994에서 검증 민감도 0.753, 특이도 0.752다. 논문의 SA BRI 학습 AUC는 0.867이다. 컷오프는 원문 Table 4에 없으므로 이 값은 분석자 추정치다. BRI와 WHtR는 단조 변환 관계여서 같은 사람과 가중치에서 직접 지표 ROC가 동일하다. 원문의 두 AUC는 서로 달라 모형 등 미보고 설정을 확인해야 한다.
