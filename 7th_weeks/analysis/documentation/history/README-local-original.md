## 논문 읽기
횡단면 NHANES 2011–2018에서 대상자 8,159명. 논문은 DXA 근육량/BMI가 남성 0.789 미만 또는 여성 0.512 미만이면 SA, SA이면서 BMI 30 이상이면 SO로 정의한다. 이 연구의 낮은 근육량 기반 정의를 임상적 근력·기능까지 확인한 근감소증 진단과 동일시하지 않는다. 2001–2004년 BIA 자료는 별도의 검증이다. 관찰 시점이 같으므로 발생 예측이나 인과효과가 아니다.

논문의 Table 3 모델 1은 단변량, 모델 2는 연령·성별·인종·빈곤·교육을, 모델 3은 이에 고혈당·고혈압·고콜레스테롤·신체활동 부족·좌식시간·열량·단백질 섭취를 더한다. 저자 변수 코딩·OR 증가 단위·결측 및 예측 모형의 단계적 선택 세부를 확인해야 한다. 논문은 모든 분석에 survey 가중을 사용했다고 기술하지만 ROC의 구체적인 가중 방식은 불명확하다.

논문 Table 4는 SA의 BRI AUC 0.867, WHtR 0.862, SO의 BRI 0.855, WHtR 0.857을 보고한다. 표에는 AUC·95% CI·Youden 지수·민감도·특이도가 있으나 컷오프 수치는 없다. ROC 본문은 지표별 단순 ROC가 아니라 단계적 회귀 후 모형을 설명하므로 예측모형 확정 전 단순 지표 ROC를 Table 4 재현으로 해석할 수 없다. 모델 점수의 컷오프와 지표 자체의 컷오프 역시 다르다.

## 초기 탐색
`analysis/src/initial.py`는 기존 5주차의 DEMO/BMX 원본과 CDC에서 새로 받은 DXA 자료를 SEQN으로 결합하고, 공변량 결측을 적용하지 않은 후보 집단에서 FNIH 기준의 사지 제지방량을 이용한 SA/SO와 인체계측 지표를 계산한다. 논문의 'total skeletal muscle mass' 문구와 사지 근육량 구현 간 차이는 미해결이다. 검사 가중치 WTMEC2YR/4는 후보이며 논문의 정확한 가중치 선택은 미확인이다.

`analysis/runs/initial/`에는 선정 흐름, 입력 해시, 비보정 가중 OR 점추정, 직접 지표의 가중 ROC와 그림이 있다. 표본은 모델 3 공변량 결측을 제외하지 않아 논문 8,159명과 다를 수 있다. 분할은 결과별 층화 무작위 8:2, seed 42라는 분석자 선택이며 저자 분할이 아니다. 학습 집합의 Youden 최적 컷오프를 검증 집합에 고정한다. LBSIZ는 전체 후보 집단의 비가중 평균·표준편차를 사용한 임시 정의로, 학습·검증 분리 전에 계산했으므로 데이터 누출 가능성이 있다. 직접 지표 ROC의 순위는 이 선형 표준화에 영향을 받지 않지만 모델 개발에서 이를 학습 집합 기준으로 고쳐야 한다.

이 단계의 OR은 가중 점추정만 제공한다. NHANES의 층화와 군집을 반영한 설계 기반 표준오차가 아직 구현되지 않아 신뢰구간과 p값을 제공하지 않는다. 단순 가중 GLM의 기본 표준오차를 복합표본 추론으로 사용하지 않는다. 검증 집합은 무작위 내부 분할이고 외부 검증이 아니다.

### 이번 실행에서 관찰한 값
전체 39,156명 중 20세 이상 22,617명, 위의 기본 측정과 가중치가 있는 후보 10,745명이다. 이 후보에서 SA 941명, SO 632명이며 논문의 최종 8,159명과 같은 표본이 아니다. 학습 집합의 직접 지표 ROC에서 SA BRI와 WHtR의 가중 AUC는 각각 0.830, SO는 각각 0.914였다. 두 지표는 허리둘레/키의 단조 관계이므로 동일 방향의 직접 ROC가 같다. 논문 Table 4와 차이는 모집단, 공변량, 예측모형, 분할 등 여러 요인이 겹쳐 있어 원인을 아직 특정할 수 없다. SO의 경우 BMI ≥30 자체가 결과 정의의 일부이므로 BMI 기반 판별 성능을 독립 진단정보로 해석하면 안 된다.
