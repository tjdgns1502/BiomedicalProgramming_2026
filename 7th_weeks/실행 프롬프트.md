# 7주차 실행 프롬프트

기준: 이전 5주차 `실행 설계/05-prompts-v2.0-original.md`와 `05-prompts-week5.md`. 논문: Wu et al. 2024, PMID 39738342, DOI 10.1038/s41598-024-82751-7. 작업 루트는 이 파일의 폴더. Python은 uv를 사용한다. README와 `analysis/runs/initial`은 사전 탐색이며 검증된 재현이 아니다.

논문과 과제의 추론 흐름을 학습자가 따라갈 수 있도록 정리하고, NHANES 2011–2018에서 선정·지표·공변량·가중치의 근거를 공식 코드북과 원문에 연결하라. Figure 1의 단계별 분모, Table 3 모델별 OR·95% CI·p값, Table 4 AUC·Youden·민감도·특이도, Figure 2 ROC를 재현하고 원문과 대조하라. 저자의 코드·보충 데이터·불명확한 선택과 단위를 조사하고 불명확한 설정은 후보로 기록한다. 논문에 컷오프 수치가 없다는 점을 명시하고, 분석자가 구한 컷오프는 학습 집합에서 고정하여 검증 집합에서 평가한다. ROC 모형에 단계적 선택이 포함되므로 단순 지표 ROC와 논문 모형을 구분한다.

복합표본 층·PSU와 적절한 가중치에 기반한 추론을 구현하고 단순 가중 GLM의 표준오차를 설계기반 결과로 표시하지 않는다. 입력 출처·해시·버전·선정 흐름·코드·환경·시드·결과를 기록하고 같은 자료의 내부 검증과 별도 코호트 검증을 구분한다. 데이터 누출과 BMI가 종속변수 정의에 포함되는 구조를 점검하며 횡단면 결과를 인과 또는 미래 발병 예측으로 해석하지 않는다. 원문 미보고, 재현 차이, 구현 미완료를 결과와 구분하고 독립 검토하지 않았다면 명시한다. 분석·그래프·학습 노트에 같은 데이터 버전과 모형을 반영한다.
