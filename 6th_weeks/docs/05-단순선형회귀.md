# 단순 선형회귀

자료 버전: `wallen-hr-355eb8cf25fa3f49fd17` · 실행: `R1-20261024` · 단위: bpm · 작성일: 2026-10-24

## 질문과 모형
시계 평균이 ECG와 어떤 직선 관계에 있는가? y=시계, x=동시 ECG이고 y=a+b×x+잔차입니다. R lm(device_bpm~reference_bpm)을 기기마다 별도로 적합했습니다.

## 최소 계산과 확인
b=Sxy/Sxx, a=y평균−b×x평균입니다. 절편이 있는 단순회귀의 R²=r²를 확인했습니다. 평균반응 CI와 개인의 예측구간·LoA는 다릅니다.

## 해석과 한계
Fitbit의 기울기 0.644는 관측 범위에서 ECG 변화보다 시계 평균의 변화가 작게 나타난다는 기술입니다. y=x의 절편0·기울기1과 비교하되 학습자료의 회귀 적합을 외부 예측 성능이나 인과효과로 표현하지 않습니다. ECG 자체도 측정값이므로 OLS가 오차 없는 참값의 보정식을 증명하는 것은 아닙니다.
